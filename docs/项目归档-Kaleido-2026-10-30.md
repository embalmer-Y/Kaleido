## §2 终态基线（2026-10-30 晨，backlog 口径）

- **语音链**：真人唤醒 mono 6/6 全命中；截断→首音 **1.5-1.6s**（M1.5 验收线 1.5s 基本达成，尾差=LLM 建连 ftok ~820ms）；全链 soak 绿；内存 int 287KB。
- **平台**：osptek P4C5 10.1"（P4 v3.2 + C5 esp_hosted 3.0.10 host / C5 v661 slave，WiFi 已恢复）；10.1" DSI 60fps 垂直同步零撕裂定稿；2" CO5300 AMOLED（460×460）已点亮，参数集验证（1lane/330Mbps/LDO3@2.5V/列偏移10）；Korvo-1（S31）与一块 P4 已损坏（RMA/弃用待定）。
- **四条链路终态**（详细实现见 `docs/design/语音链路realtime快线-参考优化方案v1.md` §1.3 所引各档）：
  - 唤醒：esp-sr 2.6.0 wn9 "你好小智"（TTS 鲁棒变体），**V-40 mono 单声道无 AEC**（MR+AEC 路线判死回退）；自定义词"你好墨墨"= microWakeWord/onnx-wakeword 双轨试点（32 号调研）
  - ASR：百炼 DashScope WS 直连 `paraformer-realtime-v2`（16k PCM 流式，TLS 锚定 GlobalSign R46）
  - TTS：MiniMax t2a_v2 `speech-2.5-hd-preview` / `female-tianmei`（HTTPS SSE→**已加连接复用+采音期预热**）；百炼 cosyvoice-v3-flash 为 Kconfig 备选
  - LLM：MiniMax-M3（关思考）主选 / qwen-plus 回落，OpenAI 兼容 SSE，句读切送 TTS（clause_pump）
  - 网关：`server/voice-gateway`（Python WS 透传，9100）完成+评审+实测，**预留未接线**
- **灵魂内核**：W0-W4（驱力/评价/情绪九维/点火仲裁/记忆）组件化入库；soul-test 板端 18/18；convo-stage HIL 集成语音+表达+记忆+自主思考轮（W3）；表达层 v2 kex_face 内核 13 测试过屏。
- **BYOK**：kaleido_secret（NVS ds_key/mm_key→CONFIG 缺省链）+ 首电 SoftAP Web 向导（V-42 实测）。
