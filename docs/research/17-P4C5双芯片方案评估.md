**输入**：W-2/W-3/W-4 实测记录（M1-真机验证记录.md）+ 本地 IDF v6.1 源码核查 + 网络调研（来源见 §6，访问 2026-10-24）。

## 结论先行

1. **P4+C5 技术上成立且更成熟**：P4 为 IDF stable target，音频（PDM RX×4）、显示（PPA/GPSPI-QSPI）、摄像头（CAM/ISP）、esp-sr 全支持【官方确认（本地 IDF 源码+组件清单）】；esp_hosted v2.12.9 官方支持 P4+C5 over SDIO（2025-12 起）【官方确认】。
2. **代价真实存在**：模组合计 ≈$8.4–9.2（P4NRW32 $4.67 缺货中 + C5-WROOM ¥35≈$4.47 现货）vs S31 单模组 $6.2 → **BOM +$2.2–3.0/台**；另有双芯片 PCB（SDIO 走线/双烧录口/双电源域）、双固件维护（esp_hosted 版本管理）、结构高度与认证面变化。**C5 无经典蓝牙**——未来 BT 音频（A2DP）路径受限，与"音频第一优先"存在潜在冲突。
3. **关键反证：W-4（TLS 卡死）很可能不是 S31 芯片问题**——ESP-Mosaico 即 S31+ESP-Claw 的量产产品，核心卖点就是云端 Chat Coding（HTTPS 必须工作）【官方确认】；且 esp-idf 无 esp32s31 TLS 同类报告，esp-claw 的 http_reuse 组件刚被 #157 修过 use-after-free。W-4 更可能是 esp-claw 在 S31 上的软件残留（配置/内存/http_reuse），**在未定位 W-4 根因前切芯片 = 可能为软件问题付出硬件返工代价**。
4. **建议：双轨制，暂不切换**。A 线（主线）：48–72h 定位 W-4（mbedtls 调试构建 + 二分排查 http_reuse/证书/MSS/内部堆）；B 线（备案）：本报告即 P4+C5 迁移评估基线，若 W-4 定位为 S31 SDK/硅片级且短期无修 → 触发切换决策（R1 红线变更），预估返工 2–3 周。
5. S31 已付的学费大多是**一次性**的：W-1（上游板定义）、W-2（官方已修已 backport）、esptool stub 缺失（操作层面）；真正开着的只有 W-4。

## 2. W-4 根因假设排序（为何"先查后切"）

1. **esp-claw http_reuse 残留缺陷**（最可疑）：#157 刚修过该组件 use-after-free；我们 TCP 建立成功、TLS 等不到数据的现象与连接复用层的状态机残留吻合。
2. mbedtls 从 PSRAM 分配（`MBEDTLS_EXTERNAL_MEM_ALLOC=y`）× S31 PSRAM 访问时序问题（W-3 同族）——#157 未覆盖的路径。
3. lwIP TCP MSS/分片（大证书链 TLS 记录收不全）——经典 ESP 症状，配置可试。
4. S31 TLS 硅片级缺陷（**可能性最低**：Mosaico 量产反证）。

48–72h 排查路径：mbedtls 调试日志构建（`CONFIG_MBEDTLS_DEBUG` 级别 4）定位握手卡点 → 关 `MBEDTLS_EXTERNAL_MEM_ALLOC` 复测 → 绕过 http_reuse 直连复测 → 调 `LWIP_TCP_MSS=1360` 复测。每步 30 分钟级。

## 3. 若切换：迁移影响清单（B 线预案）

- **可原样保留**：显示模组（CO5300 QSPI）、功放/喇叭/箱体（TAS5805M+CMS-2594）、PDM 麦（MSM261DDB031）、电池/充电/电源树主体、摄像头（OV2640 DVP，P4 的 ISP 反而更强）、结构/成本基线、Kaleido-Claw 软件架构（BSP 层适配）、KApp 框架/KShell/LLM 探针工具。
- **需重做**：kaleido_bsp（引脚表/电源时序）、esp_hosted 集成层（新组件 kaleido_net）、双固件构建/烧录/OTA 流水线、PCB 全部（约等于回到 G3 前夜）、部分 G1 验证项在 P4 上重跑。
- **预估**：2–3 周返工（并行推进情况下）；BOM +$3 内可控（工作预算 $50 有余量，中值 $43+3=$46 仍达标）。

## 4. 决策建议

**维持 S31 为主线，立即启动 W-4 攻坚（48–72h 时间盒）；P4+C5 作为正式备案不投入开发资源。** 触发切换的条件（满足其一即提请 R1 变更）：①W-4 定位为 IDF/S31 SDK 级且乐鑫无修复时间表；②S31 国内模组供应（V-06 询价）失败；③G2 期间再出现 ≥2 个 S31 独有阻断级问题。

## 5. 事实分级备注

- 【官方确认】P4 stable 于 IDF、esp_hosted v2.12.9 支持 P4+C5 SDIO、Mosaico=S31+Claw 云端 Chat Coding 产品、P4/C5 模组价格与库存（LCSC 页）。
- 【待验证】P4NRW32/C5 大批量 1k 实价与交期（缺货中，需代理询价）；esp_hosted 在 IDF v6.1 的官方兼容声明（社区 CI 已过 v6.0）；C5 经典蓝牙缺失对 BT 音频路线的实际影响（esp_hosted 传 BLE only）。
