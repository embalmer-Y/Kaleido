# 13-供应链与成本调研

> 访问日期：2026-10-23。本报告覆盖：PCB/PCBA 报价（嘉立创为主）、元件渠道对比、
> **1k 台成本基线表（用于校准 R4 的 $55 目标）**、可达性结论与敏感性分析、MOQ 风险。
> 汇率假设：**1 USD = 6.7 CNY**（依据：2026-10 下旬央行中间价约 6.718，中国银行 2026-10-23 钞卖价约 6.69），
> 即 $55 ≈ **¥368.5**（含 3% 损耗后的整机 BOM 上限）。
> 除注明外金额为人民币；所有区间均标注证据级别与推导依据，未经实际询价闭环。

## 结论先行

1. **$55 目标（1k 台、含 3% 损耗）判断：可达，且有余量**。成本基线合计（含损耗）约 **¥164–296（$24–44）**，
   中位约 ¥228（$34），对 $55（¥368.5）有 20%–56% 余量。置信度：**中**（关键单价多为单渠道快照/估算）。
2. 最大的量敏感项是**结构件**：注塑模具摊销按 1k 台计 ¥20–60/台；若产量跌到 500 台，摊销翻倍，
   若只有 100 台则摊销 ¥200–600/台——**$55 目标本质上是"1k 台起步"的目标，量缩水最先杀死它**。
3. 第二敏感项是 **AMOLED 模组**（¥28–45，若 460×460 高规屏按 ¥50–60 计，+¥15–30）与**主控模组**
   （ESP32-S31 模组价格未公布，按 S3-WROOM-1-N16R8 ¥21.5 平替估算 ¥22–35）。
4. PCB/PCBA 在国内是"买方市场"：嘉立创四层板小批量 **450–460 元/㎡**【官方确认】、华秋最低 **410 元/㎡**【供应商声称】，
   80×50mm 4 层板 @1k 约 **¥2–3/片**（推导见 §1.1）；SMT+钢网+测试摊销约 **¥7–15/片**。
5. 元件渠道策略：**立创商城为主渠道**（国产料全、发货快、与嘉立创 SMT 联动），**贸泽/DigiKey 兜底 TI 等原厂料**
   （DigiKey 标准运费 $30、单价偏高）；1k 档三家都要拉阶梯价核对。
6. 电池是唯一有**法规级采购门槛**的料：UN38.3 报告 + IATA 运输限制（空运电量 ≤30%、UN3090/3091），
   必须选可提供 UN38.3 摘要的电芯厂。
7. 下一步闭环：向嘉立创提交实际 Gerber+BOM 询价（PCB+SMT 一口价）、向鱼鹰光电询 1k 阶梯屏价、
   锁定乐鑫 S31 模组渠道价——三个动作完成后本基线表升级为"冻结版成本表"。

## 1. PCB / PCBA

### 1.1 PCB（4 层，80×50mm，1.6mm，ENIG 或喷锡）

【官方确认】嘉立创官网价格页（2023-05-22 发布，页面"最新动态"显示 2026-09 四层板报价 **460 元/㎡**、A1 级板材；
小批量 ≥1㎡ 统一价）。页面实例：**100×100mm × 1000 片（10㎡）总价 ¥5,274**（≈¥5.3/片，含工程/测试等杂费；
10㎡×450=¥4,500，差额约 ¥774 为附加费）。

推导（80×50mm = 0.004㎡）：
- @1000 片：4㎡ × 460 = ¥1,840 + 附加费（按 100×100 实例比例约 +17%）≈ **¥2,100–2,600 → ¥2.1–2.6/片**；
- @100 片：0.4㎡ 不足 1㎡，走打样/小批量价，估 ¥300–500 → **¥3–5/片**【估算】。

### 1.2 SMT（按 BOM 料数 100–150、焊点约 400–600/片估）

【官方确认/供应商声称】嘉立创 SMT（jlc-smt.com）：
- **经济型**：贴片工程费 **¥50/单、钢网免费**，基础库订单约半天交期；适合打样。
- **标准型**收费 = 贴片工程费 + 焊点费 + 插件工程费 + 器件费 + 上料费 + 包装费 + X-Ray 费 + 治具费；
  **换料（上料）费阶梯**：0–10 种器件 ¥10/种、11–50 种 ¥5/种、51–500 种 ¥3/种（第三方文章口径【供应商声称】）；
  预定器件换料费 **5 元/一种**（整单一次，非每片）。
- **器件损耗**：整盘或 1000 颗（取小）以上部分加收 0.2%；单价 <¥1 器件加收 0.4%；高价值芯片 0 损耗。
- 起订 2 片，可支持到 5000 片大批。

@1k 片、约 130 个料号（~400–600 焊点）推导：
- 工程费+钢网+治具：一次性约 ¥500–1,500 → 摊 ¥0.5–1.5/片；
- 上料费：130 × ¥3–5 ≈ ¥400–650（一次性）→ 摊 ¥0.4–0.7/片；
- 焊点费+损耗+包装：估 ¥4–9/片【估算】；
- **SMT 小计 ≈ ¥5–11/片**；加 ICT/FCT 测试治具与人工（¥1–4/片）→ **贴装+测试合计 ¥7–15/片**【估算】。

## 4. $55 可达性判断与敏感性分析

**判断：可达（1k 台口径）**。条件：① 实际下单量 ≥1k；② AMOLED 模组 1k 阶梯价 ≤¥45；
③ S31 模组价 ≤¥35。三项均有现实证据支持但未询价闭环。

单变量敏感性（对 ¥368.5 上限的冲击，其余项取中值）：

| 变量 | 变化情景 | 单台影响 | 后果 |
|---|---|---|---|
| **产量（经结构摊销）** | 1k → 500 台 | +¥20–45 | 仍可达（中值 ~¥250） |
| | 1k → 100 台（打样几十台量产版） | +¥180–540 | **不可达**（结构单项即 ¥200+/台）→ 打样期必须走打印路线（报告 12） |
| AMOLED 模组 | ¥36 → ¥60（460×460 高规/小厂） | +¥25 | 仍可达，余量收窄到 ~13% |
| 主控模组 | ¥28 → ¥45（新品缺货溢价） | +¥17 | 仍可达 |
| 音频链路 | 定制喇叭 + T/S 开发转嫁 | +¥10–20 | 仍可达；NRE（开声腔模具/喇叭定制费）不进 BOM 但进项目现金 |
| 汇率 | 6.7 → 7.2（+7.5%，仅美元计价料受影响，占比低） | +¥3–6 | 影响小 |
| SMT | 双面贴/BGA X-Ray 全检 | +¥3–8 | 影响小 |

**最伤目标的排序：产量（结构摊销） > AMOLED > 主控模组 > 音频定制化**。前两项合计波动可吃掉
大部分余量，是 G2 冻结 BOM 时必须最先询价锁定的两项。
