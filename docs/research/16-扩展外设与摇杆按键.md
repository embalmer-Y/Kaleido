# 16-扩展外设与摇杆按键调研

| 版本 | 日期 | 作者 | 状态 |

> 背景：2026-10-24 需求增补 ② 磁吸扩展接口需支持接入迷你按键/手柄摇杆类输入配件；③ 整机允许更大更厚。
> 磁吸接口基线见报告 10（6pin：`5V/GND/GND/3V3/SDA/SCL` + AT24C02 EEPROM @0x50），供电预算见报告 11-B6（5V/1A 目标）
> 与报告 10-§4.1（默认限流 500 mA 起步）。信息访问日期统一为 **2026-10-24**。
> 事实分级：【官方确认】/【供应商声称】/【社区经验】/【待验证】。

## 结论先行（≤10 行）

1. **摇杆选型（磁吸配件场景）主选：传统电位器双轴摇杆模组**（PS2 类双轴带中键模组，淘宝 **¥1.4–4.2/件有据**，
   1688 批发更低）——**不是保守，是被磁吸接口决定的**：霍尔/TMR 摇杆靠磁场感测位置，与配件吸合面的强磁铁天然冲突，
   Nintendo Switch 2 正因 Joy-Con 磁吸连接放弃霍尔摇杆（Lumafield CT 拆解/iFixit/社区多源）【社区经验，多源一致】。
2. 霍尔/TMR 摇杆（淘宝 ¥5.80–22.9，Gulikit/锦读等）防漂移寿命优势真实存在，**留给两类场景**：主机内置摇杆（v2 形态）
   或远离磁铁 ≥15 mm 并实测标定的配件设计——列为备选路线，不做首发承诺。
3. **配件电子方案主选 A：配件内置 CH32V003**（¥0.85@立创，RISC-V 48MHz，I2C 从机 + 10-bit ADC）读摇杆 ADC + 扫键阵，
   经磁吸口 I2C 上报；**纯按键配件选 C：IO 扩展芯片**（CH422G ¥1.91 无中断/时序非标；PCA9555 ¥8.5 带 16-IO+中断）；
   **B（模拟电压直接过 POGO 进 S31 ADC）否决**：6pin 无专用 ADC 脚、与 EEPROM ID 读取冲突、POGO 接触瞬断引入毛刺、
   无配件侧校准/防呆——三项硬伤。
4. 机械轴迷你键盘配件**可行**：CH32V003（QFN20 档）+ 4×5 键阵 = 20 键，芯片+阻容 <¥3，总 BOM ¥10–25 档
   （轴体单价待核）。ESP32-C6 模组（¥17.21）仅高档"无线手柄"类配件才值得上。
5. **5V 供电预算核算：输入类配件典型 <30 mA、带 RGB 峰值 <100 mA**——报告 10 的**默认 500 mA 限流即有 5–15×
   富余**，报告 11-B6 的 1A 能力完全无需为输入配件保留（那是电池背夹/副屏的预算）；输入配件连 3V3 都可不用。
6. **协议草案**：输入类配件 MCU 挂 I2C **0x22**（输入类预留段 0x20–0x27），16 字节报表（magic/类型/特性/帧序号/
   16 键位图/X·Y int16/中键/状态），EEPROM ID 仍在 0x50 不动；主机 500 Hz–1 kHz 轮询单事务读回，
   **端到端延迟 ~5–18 ms，<20 ms 游戏手感目标可达但建议游戏配件上 8pin（+IRQ）**。
7. 结构输出（kaleido-mech）：摇杆操作侧向力经吸合面传递，**定位柱必须承剪**（磁吸只抗拉不抗剪）；摇杆模组含帽
   总高与配件壳厚需索样测绘后冻结（估 15–22 mm，与"整机允许更厚"增补兼容）。
8. 先例：Mosaico 官方**无任何输入类配件**（最接近的是多功能交互子板的 2 按键/触摸）→ 输入配件是 Kaleido 差异化卖点；
   Playdate 社区用串口坞接键盘/手柄（Playwrite Dock）、自制相机配件，证明掌机外设的社区需求真实存在。
9. 整体置信度：**中**——配件侧器件价格/供货有据（立创在售），摇杆模组尺寸/寿命/操作力全部缺一手规格书（1688/淘宝
   渠道特性），已列索样验证清单。

## 二、详细分析

### 1. 摇杆方案

- **磁冲突是第一约束**。报告 10 已定吸合面布置 2–4 颗 N52 钕铁硼磁铁（150–3000 gf 吸力档）。霍尔摇杆与 TMR 摇杆
  均以磁场感测摇杆位置（磁铁装在摇杆头上）——主机侧强磁铁将直接进入传感器量程造成读数偏置/饱和。**业界实证**：
  Nintendo Switch 2 的 Joy-Con 采用强磁吸连接，因而弃用霍尔摇杆、沿用重新设计的电位器方案（Lumafield CT 拆解分析
  指出磁吸系统与霍尔感测存在"技术冲突"；iFixit 拆解确认仍为电位器；Reddit 社区讨论同口径）【社区经验，多源一致，
  来源 2/3/4】。第三方已推出 Switch 2 兼容的磁吸霍尔杆，说明**可工程化**（屏蔽/标定），但那是成熟厂商的量产功课，
  Kaleido 首发不应替用户背这个风险。
- **电位器方案**：PS2 类双轴带中键（5 线：VCC/GND/X/Y/SW）模组淘宝 ¥1.4–4.2（来源 5/6），1688 批发更低。漂移问题
  通过 A 方案 MCU 的出厂校准（中心点+端点+死区）大幅缓解；掌机 AI 伴侣场景摇杆操作强度远低于竞技游戏，通用档
  寿命（数十万次级，【待验证】）预计够用。**结论：首发配件主选**。
- **霍尔/TMR**：价格 ¥5.80（批发）–22.9（零售，锦读 TMR，来源 1），Gulikit 为知名品牌。保留两条上线路径：
  ① Kaleido 主机 v2 内置摇杆（远离磁吸口即可）；② 配件内霍尔杆距吸合面磁铁 ≥15 mm 且实测标定【设计经验值，
  待验证】。协议中已预留"磁干扰告警"状态位（§5）。

### 2. 配件侧电子方案（A/B/C 详评）

- **方案 A（主选）**：CH32V003（官方页：RISC-V 48MHz、I2C 支持从机、10-bit ADC、3.3/5V 供电，来源 7）一颗芯片完成
  摇杆双 ADC 采样、按键扫描（含键阵）、去抖、校准与 I2C 从机报表。SOP-8 装 6–7 个 IO 够"摇杆+4 键"；QFN20 档做
  键盘阵。生态佐证：MuseLab nanoCH32V003 评估板 $1.50，Hackster 报道其典型用途即包括按键扩展板（来源 9）【社区经验】。
  BOM：芯片 ¥0.85 + 被动 ≈ **¥1.2/配件**（立创价，1k 档更低）。
- **方案 B（否决）**：三个硬伤——① **6pin 草案没有模拟脚**：SDA/SCL 一旦改 ADC，EEPROM ID（报告 10 §4.3，模块识别
  机制的地基）与热插拔检测同时失效；② S31 ADC 固定映射在 GPIO42–57（datasheet §4.2.3.3，报告 01），意味着主机侧
  要为主持"某类配件"永久牺牲两个本就紧张的通用脚；③ POGO 接触瞬断在模拟域表现为**尖峰毛刺=摇杆乱跳**，数字域
  只是可重试的 NACK。数字传输天然容错，这是磁吸连接器的既有结论（报告 10 §2.2）。
- **方案 C（纯按键配件主选）**：CH422G ¥1.91（8 IO，无中断、I2C 时序与标准略有差异需驱动适配，来源 14）；要中断或
  >8 键则 PCA9555 ¥8.5（16 IO+INT，标准协议，TI datasheet，来源 12/13）。与 EEPROM 同总线共存无冲突（地址
  CH422G/PCA9555 均在 0x20–0x27 段，避开 0x50）。**注意 CH422G 无中断 → 按键配件靠主机轮询（≤1 kHz 轮询延迟可忽略，
  见 §6 预算）**。
- **ESP32-C6**（¥17.21，立创，来源 10）：配件自带 Wi-Fi/BLE 的"无线手柄"路线，延迟（无线）与配对复杂度都不利于
  首发体验；仅当社区提出"隔空操控"需求再立项。

### 3. 迷你按键键盘配件可行性

- 结构：CH32V003 + 二极管键阵。QFN20 约 18 个可用 IO → 4 行×5 列 = 20 键（数字+方向+功能），机械轴（MX/类 MX/
  Choc）单价与键帽成本未核【待验证：立创查 Kailh/佳达隆阶梯价】；按通用行情估轴体 ¥0.5–2/颗【社区经验，待核】。
  配件总 BOM 估 **¥10–25**（PCB+轴+键帽+外壳摊销另计），零售 ¥49–69 档可成立。
- 复用价值：键盘配件固件与摇杆配件同一份代码框架（键阵扫描+I2C 报表），一次开发两类产品。
- 先例：Playdate 社区 Playwrite Dock（3D 打印坞站，给无 USB 外设支持的 Playdate 加键盘/手柄，走串口，来源 19）
  ——证明"掌机+物理键盘/手柄"的社区需求真实；Kaleido 的正式化优势是磁吸+供电+EEPROM ID 即插即用。

### 4. 配件供电预算核算（5V 轨）

| 负载项 | 典型电流 | 依据 |
|---|---|---|
| CH32V003 @48MHz | 数 mA 级（<10 mA） | 官方页宣称低功耗，具体值【待验证→datasheet】 |
| 电位器摇杆 | 0（无源分压） | — |
| 霍尔传感器（如启用） | 数 mA/轴 | 【待验证→规格书】 |
| CH422G/PCA9555 | 静态 µA–mA 级 | 【待验证→datasheet】 |
| 装饰 RGB（可选） | 20–60 mA | 设计选项 |
| **输入类配件合计** | **典型 <30 mA，峰值 <100 mA** | 本表汇总 |

结论：报告 10-§4.1 的**默认 500 mA 限流对输入类配件富余 5–15×**；报告 11-B6 宣传的"扩展 5V/1A（Mosaico 100 mA
的 10×）"预算完全不需要为输入配件让步——1A 能力留给电池背夹/副屏/补光灯等未来模块。**输入配件甚至可以不接 3V3**
（CH32V003 宽压 3.3/5V，直接挂 5V；或将 3V3 留作电平参考）。附带提醒：Mosaico V1.0 曾因扩展模块负载拉垮内部电源轨
而返修（报告 11-A1），Kaleido 扩展电源轨独立隔离的设计（报告 14 §2）已覆盖此风险，输入配件侧再加 TVS+缓启即可
（报告 10-§5.5 要求）。

### 5. 协议草案：输入类配件 I2C 寄存器映射（v0.1，供 ADR 评审）

**总线约定**：沿用磁吸口 I2C（400 kHz，上拉在主机侧常供电）；EEPROM ID 保持 **0x50** 不变（报告 10 §4.3）；
**输入类配件功能寄存器默认地址 0x22，可配置段 0x20–0x27**（与 CH422G/PCA9555 默认地址段天然重合，纯按键配件即
芯片本身，MCU 类配件模拟同风格寄存器接口）。主机已占地址（触摸 0x15、电量计 0x36、IMU 0x68、功放等）一律避开。

**输入报表（一次事务连读 16 字节，MCU 类配件）**：

| 偏移 | 字段 | 说明 |
|---|---|---|
| 0x00 | MAGIC/VER | `0x4B`（'K'）高 nibble=协议版本 v0.1 |
| 0x01 | TYPE | 0x01 纯按键 / 0x02 摇杆+按键 / 0x03 键盘阵列 / 0x04 触发器手柄 |
| 0x02 | FEATURE | bit0=XY 轴 bit1=中键 bit2=L2/R2 模拟 bit3=霍尔（磁敏）告警上报能力 |
| 0x03 | SEQ | 帧序号，滚动 +1（主机判丢帧/瞬断/拔出） |
| 0x04–0x05 | BTN 位图 | 16 键，bit0=A、bit1=B、bit2=X…（键值表随 TYPE 注册） |
| 0x06–0x07 | X | **int16 LE，0=中心**（配件侧完成校准+死区） |
| 0x08–0x09 | Y | 同上 |
| 0x0A–0x0B | Z/中键 & L2/R2 | 按 FEATURE 解释 |
| 0x0C | STATUS | bit0=磁干扰告警（霍尔方案）bit1=低电 bit2=校准请求 |
| 0x0D–0x0F | 保留/CRC8 | CRC 覆盖 0x00–0x0E（可选启用） |

**时序与延迟预算（<20 ms 目标）**：

| 环节 | 预算 | 说明 |
|---|---|---|
| 配件采样周期 | 1 ms（1 kHz 扫描） | CH32V003 48MHz 余量充足【估算】 |
| I2C 传输 | 0.4 ms | 400 kHz 下 16B 连读（地址+16×9 bit） |
| 主机轮询间隔 | 2 ms（500 Hz） | 游戏模式 500 Hz；省电模式 50 Hz |
| 事件→UI 帧呈现 | ≤16.7 ms | 60 fps 渲染管线（显示专题帧率目标） |
| **最坏端到端** | **~20 ms** | 500 Hz 轮询+60fps；**1 kHz 轮询→~18 ms** |

结论：<20 ms 可达但无余量；**游戏手感类配件建议采用 8pin 接口（+IRQ 引脚，报告 10-§4.2）**：按键事件即触发中断，
摇杆仍轮询，最坏延迟再降 2–4 ms。拔出检测：SEQ 停增 + NACK + 电源欠压三判据（报告 10 §4.3 流程不变）。

### 6. 结构约束输出（给 kaleido-mech）

1. **定位柱承剪**：摇杆操作（拨杆侧推）在吸合面产生剪力与力矩，磁吸力只提供法向保持——**剪力必须由定位柱承担**。
   建议输入类配件定位柱加粗至 Ø2.0、插入深度 ≥2 mm（对比通用配件 Ø1.5，报告 10-§5.1），配合段公差按 SLA 0.15 mm
   验证。摇杆操作力/力矩实测值（索样后）回填此条。
2. **摇杆高度与配件壳厚**：电位器模组本体高度 + 摇杆帽行程 + 壳壁，估配件总厚 15–22 mm【待验证：索样测绘】；
   需求增补 ③"整机允许更大更厚"已为其留出空间；envelope 图（V-14）追加"最大配件投影"约束项。
3. **磁铁远离摇杆**：电位器方案无磁敏感，但为未来霍尔配件兼容，配件内磁铁位与摇杆位**默认拉开 ≥15 mm**并写入
   配件设计指南【设计经验值，待验证】。
4. **防呆**：继承报告 10 非对称定位柱 + 对角异极磁防呆（90°/180° 双防）；摇杆配件 X/Y 轴向敏感，唯一可吸方向必须
   使 X 轴指向屏幕横向——结构上由定位柱排布保证，不允许"能吸上但轴向旋转 90°"的第二姿态。
5. **受力壳体**：摇杆操作时手指下压配件壳，壳体需闭合刚度（不翘曲、不压弹 pogo），pogo 压缩行程按连接器规格书
   （V-12 索样）取中位偏上。
6. **配件坞定位面**：若首发同时出"摇杆配件+按键配件"，统一吸合面规格（同一组 pin/磁铁/柱），仅外壳不同——
   开模摊销共享。

### 7. 参考先例

- **ESP-Mosaico（官方）**：现有配件=相机模块（仅左槽）+ 多功能交互子板（GL5506 光敏+AS312 PIR+红外+6×WS2812+
  **2 按键/触摸焊盘**+AT24C02，来源 15/16）+ 8×8 RGB 矩阵灯 + $15 电池模块（报告 11）——**无摇杆/手柄/键盘类输入
  配件**。Kaleido 的输入配件线（摇杆柄、迷你键盘）在同类生态中尚无对手，属差异化卖点。
- **Playdate（Panic）**：官方无扩展口，社区从 USB 串口"外挂"：Playwrite Dock（3D 打印坞+键盘/手柄，Hackster 报道，
  来源 19）、DIY 相机配件（Retro Dodo 专题，来源 18）、社区配件汇总 Wiki（来源 17）。启示：① 掌机外设的玩家/开发者
  需求真实且愿意 3D 打印；② 官方给出**供电+识别+标准协议**（即 Kaleido 6pin+EEPROM+本报告寄存器表）能把这类玩法
  从"极客改机"变成"生态配件"。
- **掌机 DIY 社区**：xiaozhi 生态 138 板型（报告 11）证明 ESP32 类掌机的开发者基数；Kaleido 输入配件协议开源后，
  社区自制第三方配件（EEPROM 类型码注册表，报告 10 §4.3）是零成本生态扩张路径。
