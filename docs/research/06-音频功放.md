## 结论先行

1. **主选：TI TAS5805M + 外置升压 12V/≥30W 轨**——唯一有"每通道 15.4W@4Ω@12V@1%THD"官方表格背书[1]、且 esp_codec_dev 与 Linux 主线双开源驱动的 I2S 功放[7][8]；1k 价约 ¥10.2–14.6（≈$1.4–2.0），HTSSOP-28 可制造性好[9]。
2. **备选 A（EMI/音质优先）：Infineon MA12070P + 升压 10–12V**——多电平低 EMI 架构，12V/4Ω 下约 18.5W/ch（10%THD，官方曲线目读+物理校核）[4]；缺点：无官方 IDF 驱动（需自研，可参考社区 squeezelite-esp32 实现[11]）、QFN-64、1k 价约 ¥17[10]。
3. **备选 B（免升压、降功率）：2× 艾为 AW88298（I2S+片内 10.25V 智能升压）**——每片 5.2W@8Ω@1%THD[12]，esp_codec_dev 原生驱动[7]；**真实上限约 2×5W，达不到 10W**，作为"放弃 10W 目标"时的精简方案。
4. **锂电直挂不可行**：所有 ≥10W 级 I2S 功放 PVDD 下限为 4–4.5V（TAS5805M 4.5V[1]、MA12040P/70P 4V[3][4]），单节锂电 3.0–4.2V 无法直供；直挂电池只有 smart PA 路线（TAS2562 6.1W、AW88298 5.2W 单声道/片）。
5. **"10W×2"的真实含义**：正弦连续 10W/ch@4Ω 需 PVDD≥9V（P=V²/2R 反推）→ 建议升压 12V；7.4V 轨各芯片实测只有 4.8–6.4W/ch；功放余量主要价值是峰值瞬态与 DSP 限幅保护（配 3W 级微型喇叭，见报告 07）。
6. **交给电源专题的硬约束**：升压 12V/≥30W（连续 20W 输出 + 裕量）、电池脉冲放电 ≥8A@3.0V、电池+保护板内阻 ≤25mΩ（详见 §3）。
7. 用户预设的国产候选**NS4225 与 LTK5128 均非 I2S 输入**（模拟输入）[13][14]，如实降级为"模拟路径备选"。
8. **置信度：中高**（主选功率数据为官方表格级证据；升压-电池链路电流为工程计算，需 G5 样机实测闭环）。

## 详细分析

### 1. 各候选实测功率与供电轨耦合（官方数据核实）

BTL 输出物理上限 P ≤ PVDD²/(2R)。4Ω 负载下各供电轨的官方数据：

| 供电轨 | TAS5805M（4Ω）[1] | MA12070P（4Ω）[4] | MA12040P（4Ω+22µH）[3] | 结论 |
|---|---|---|---|---|
| 5V | ≈1.7/2.1W※（Fig 6-13） | ≈2.5/2.9W※（Fig 10-23，PMP2） | ≈2.3/2.9W※（Fig 10-23） | 仅 2–3W/ch，无意义 |
| 7.4V（双节仿真轨） | ≈4.0/4.8W※ | ≈5.5/6.4W※ | ≈4.9/5.7W※ | **达不到 10W**，上限 2×6W |
| 10V | ≈8.5/9.5W※ | ≈11/12.4W※ | ≈9/10W※ | 临界达标（峰值口径） |
| 12V | **15.4/18.5W（表格，p.9–10）** | ≈16.5/18.5W※ | ≈12.5/14W※ | 达标；TAS5805M 有官方表格值 |
| 反推需求 | 要 10W/ch@4Ω@1%THD 需 PVDD≥√(2×4×10)≈8.94V | 同左 | 同左 | **推荐 12V 轨** |

※为官方曲线目读值（目读方法已用 PVDD²/8 上限校核，超限读数剔除）；TAS5805M 的 12V 数值为 datasheet Table 6.5 表格值，非目读。

要点：
- MA12070P 官方表格级数据点：BTL 峰值 80W@4Ω@26V@10%THD、60W@1%；连续 2×30W@8Ω@22V 无散热器（Table 7-1，p.8）[4]——架构余量最大。
- TAS5805M 官方表格级数据点：15.4W@4Ω@12V@1%THD、18.5W@10%THD；PBTL 单声道 45W@4Ω@21V（features p.1 + Table 6.5）[1]。
- 负载下限：MA12070P/MA12040P BTL 最低 4Ω（PBTL 2Ω）[3][4]；TAS5805M BTL 由 5A 过流阈值限制，4Ω 可用[1]。**若选 8Ω 喇叭（见报告 07），各轨功率约减半，10W 目标需更高轨压，不建议。**

### 2. 直挂电池路线核实（结论：不可行 / 仅限 5–6W 级）

- TAS5805M PVDD 下限 4.5V[1]、MA12040P/MA12070P PVDD 下限 4V[3][4]：单节锂电 3.0–4.2V 放电区间完全或大部分低于下限，**直供不可行**。
- 片内升压 smart PA 单声道实测口径：TAS2562 6.1W@4Ω@VBAT 3.6V@1%THD（SLASEI7A features p.1）[2]；AW88263CS（AW88298 同级前代）5.2W@8Ω@VDD 4.2V@1%THD，datasheet 给出整机效率约 70% 时电池平均电流≈1.78A/片的算例[17]。双片立体声 = 真实 2×5.2W@8Ω，电池峰值电流 ≈5A 级。
- 该路线优点：无外置升压、电池峰流减半、BOM 小；缺点：与"10W 双通道"目标不符、单片价（TAS2562 ¥8.7–12.8）×2 后成本与主选相当但功率低一半。

### 3. 供电约束交付（电源专题输入，硬约束）

按主选 TAS5805M + 12V 轨、2×10W 正弦连续输出口径：

- **电池侧功率**：P_bat = 20W ÷ (η_amp × η_boost)。取 η_amp≈87%（datasheet 效率曲线区间的保守值）、η_boost≈92% → **P_bat ≈ 25W**。
- **电池脉冲电流**：I = 25W ÷ V_bat → **3.0V 时 8.3A / 3.5V 时 7.1A / 3.7V 时 6.8A / 4.2V 时 6.0A**（短时正弦峰值；音乐重放按 12dB 峰值因子平均仅 ≈3W/0.8A@3.7V，但动态脉冲仍达 6–8A）。
- **对电池的约束**：脉冲放电能力 ≥8A、（电芯+保护板）串联内阻 ≤25mΩ（8A 时压降 ≤0.2V）；需选高倍率 21700/高倍率软包，普通低内阻型 18650 需实测确认。
- **对升压的约束**：输出 12V/≥2.5A（30W，含 20% 裕量）、效率 ≥92%、可配置限流、软启动、OVP；瞬时跌落（boost 瞬态 + 电池内阻）不得触发功放 UVLO（TAS5805M PVDD UVLO 见 datasheet[1]）。
- **布局约束**（constraints.md §5.4）：功放 10A 级回路独立分区，升压开关节点与 PDM 麦/天线隔离。
- 降级方案约束：若采纳备选 B（AW88298×2），无外置升压需求，电池约束降为峰值 ≈5A。
- 注意 TAS5805M/MA12070P 均另需低压轨（DVDD 1.8/3.3V 或 5V VDD[1][4]），由现有 3.3V/5V 轨派生。

### 4. 输出滤波与 EMI（filterless 影响分析）

- **原理**：BTL filterless 依赖差分抵消与喇叭音圈电感滤除开关纹波。掌机喇叭内置、走线 <30mm、无外接线缆——共模辐射路径远短于音箱产品，**filterless 基本可用**。
- **MA12070P/MA12040P**：多电平（3/5 电平）+数字功率管理动态调开关频率，datasheet 明示"filterless 满功率工作 + 低 EMI"，严格 EMI 场景可加低成本 LC（建议电感 DCR >10mΩ 并加 RC 阻尼防环路不稳）[3][4]。EMI 特性为三者最优。
- **TAS5805M**：1SPW/BD 调制 filterless，datasheet 典型应用含 LC（如 4.7µH+0.68µF）与磁珠选项[1]；30–36MHz 频段近场辐射需在预兼容摸底确认。
- **微型喇叭的特殊性**：报告 07 候选喇叭音圈电感仅 ~0.003mH 级[18]，滤波作用弱，开关纹波电流偏大 → **建议每通道加 22µH+0.68µF 一阶 LC 或磁珠+1000pF**（MA12040P 官方测试即串 22µH 负载[3]），兼顾 EMI 与喇叭高频损耗。
- **与 Wi-Fi 天线共存**：开关谐波落入 2.4GHz 频段的风险主要来自升压环节（非功放本体），布局上功放/升压区远离模组天线净空区（constraints.md §5.4 已有规定）。

### 5. 开源驱动与软件生态（R3 合规）

- **TAS5805M**：esp_codec_dev 官方组件含 `device/tas5805m/tas5805m.c`（esp-audio-dev 仓库 main 分支，本会话经 GitHub API 核实文件存在）[7]；Linux 主线 `sound/soc/codecs/tas5805m.c`（torvalds/linux master，API 核实）[8]。ES8311（麦）+TAS5805M（放）是乐鑫官方评估板常用组合，音效配置（BQ/DRC）可用 TI PPC3 生成系数、固件侧开源解析。
- **MA12070P**：无官方 IDF 驱动；主线 Linux 无 ma120x0p（核实 torvalds master codecs 目录，无该文件）[8]；社区 squeezelite-esp32 项目含 MA12070P 支持（I2C 控制实现可参考，**许可证兼容性待核查**）[11]。自研驱动工作量约 300–500 行 C（I2C 寄存器配置 + PMP profile 切换 + mute/enable）。
- **AW88298**：esp_codec_dev 含 `device/aw88298/aw88298.c`[7]，是唯一进入乐鑫官方组件的国产 I2S 功放；完整喇叭保护调校依赖艾为工具链部分闭源【待验证】。
- **TAS2562**：Linux 主线有 tas2562.c[8]，但 smart amp 保护参数（IV-sense 算法配置）依赖 TI PPC3/闭源系数生成器，R3（闭源不进必选链路）有冲突风险。

### 6. 推荐与诚实功率评估

| 口径 | TAS5805M+12V | MA12070P+12V | MA12070P+7.4V | AW88298×2 直挂 |
|---|---|---|---|---|
| 正弦连续（1%THD） | 15.4W×2（官方） | ≈16.5W×2※ | ≈5.5W×2※ | 5.2W×2@8Ω（官方） |
| 音乐峰值（10%THD） | 18.5W×2 | ≈18.5W×2※ | ≈6.4W×2※ | ≈6W×2（估） |
| 实际听感上限 | **由 3W 级喇叭+DSP 限幅决定**（联动报告 07）：连续 ≈3W×2，峰值 10W×2 余量用于瞬态 | 同左 | 峰值余量偏小 | 峰值余量小 |

- **推荐组合**：主选 TAS5805M（功率证据最硬、驱动生态最好、可制造性最好、成本最低）；备选 A MA12070P（EMI 与架构余量最好，接受自研驱动时选）；备选 B AW88298×2（若产品定义接受 5W×2，砍掉升压复杂度）。
- **"广告 10W vs 实际"**：本项目语境下"10W×2"应定义为**峰值音乐功率**（1%THD 短时正弦达标），连续正弦受限于电池（8A 脉冲）与喇叭热容量（3W 级），连续口径诚实值为 3–5W×2 + 峰值 10–18W×2 瞬态。TAS5805M 的 2×15 BQ + 多段 DRC/AGL[1] 同时承担 EQ 与喇叭保护（smart PA 功能的软件等价物），是"大功放推小喇叭"架构的必要条件。
- **被否候选**：NS4225（模拟输入，且需另配 codec 模拟输出与无 DSP 保护，仅留作极限降本备选）；LTK5128（5W 模拟输入，与需求不符）；TAS2562（单声道 6.1W、DSBGA 工艺风险、闭源保护生态）；AW88266A（2W 级，功率不足，且 esp_codec_dev 驱动覆盖的是 AW88298）。
