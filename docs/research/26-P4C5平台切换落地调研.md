## 2. WiFi 方案（P4 无射频 → C5，调研 B 结论）

**组合（锁定）**：IDF v6.1（内置 esp_wifi_remote 1.3.2）+ `espressif/esp_hosted == 2.12.9`（与板上 C5 预烧严格同版；host/slave 必须同版）。

- 关键 sdkconfig：`CONFIG_SLAVE_IDF_TARGET_ESP32C5=y`（P4 默认 C6，必须改）、SDIO 接口；SDIO 引脚走板级预设或手填（**待引脚表**）。
- esp_wifi_remote 对 esp_websocket_client/esp-tls/lwIP **完全透明**（语音链路代码零改动）；TCP 吞吐 ~50Mbps 级，远超语音需求（2×256kbps）。
- 升级路线：2.13.1 + slave 重烧（拨码切 C5 烧 0x0 合并包，或 host_performs_slave_OTA）。坑 10 条已归档（最重要的两条：勿手动加旧版 esp_wifi_remote —— <1.3.1 与 esp_hosted≥2.11 有 SDIO double-free 致命组合；`ESP_HOSTED_MEMPOOL_PREFER_SPIRAM` 在 P4 有 DMA 对齐坑，不开）。
- C5 侧 SDIO 引脚芯片固定：CLK=9/CMD=10/D0=8/D1=7/D2=14/D3=13。

## 3. 显示/音频/动画栈（调研 C 结论）

**点屏**：JD9366 不需自研——`kevincoooool/esp_lcd_jd9366 1.0.1`（已带 IDF v5/v6 双版本宏）+ osptek 原厂 init 序列（必须用 osptek 的，裕俊屏 gamma 不同）+ osptek 触摸组件。预计 0.5–1 人日。时序（两组来源一致）：DPI 76MHz / HSYNC8 HBP28 HFP40 / VSYNC8 VBP20 VFP140 / 2-lane。

**LVGL**：esp_lvgl_port 2.9.0 + LVGL 9.5.0；osptek 参考配置 = RGB565 + 全屏×2 双缓冲（PSRAM）+ `LV_DRAW_SW_DRAW_UNIT_CNT=2` + DMA2D + `avoid_tearing=false`。P4 EV 板同级配置官方 benchmark ≈64FPS@~70% CPU（800×1280）。PPA 可选（sw_rotate 加速；LVGL 9.4/9.5 另有实验性 PPA draw unit，官方称 ~+30%，有 DSI underrun 已知问题）。

**Lottie/ThorVG**：与 S31 上 V-35 结论互证——**中小区块动画（~400px）可行**（ARGB8888 缓冲放 PSRAM，esp_lv_lottie_player / thorvg 1.1.2 纯 CPU）；**全屏 800×1280 Lottie 不可行**。角色舞台落法：JPEG 硬解背景（IDF 内建 esp_driver_jpeg，P4 有 JPEG HW）+ 子区域 Lottie 角色 + LVGL 合成。无公开 P4+ThorVG FPS 数据，V-35 复测必做。

**音频**：ES8311 驱动已并入 `esp_codec_dev ~1.5`（独立 es8311 组件已废弃）；P4 EV 板 BSP 的 16k/16bit/mono 双工 I2S + `pa_pin`(NS4150) 模式可直接照抄。**WakeNet**：esp-sr 2.6.0 官方支持 P4（wn9/wn9l 确认，wn10 待验；P4 专属 GSC 波束成形/DOA 可选）。单麦 AFE input_format="M"（加 AEC 回采则 "MR"）；参考 esp-skainet wake_word_detection + voice_communication（全双工+AEC，最贴合陪伴产品"边播边听"）。
