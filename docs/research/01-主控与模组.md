# 01-主控与模组调研

专题：ESP32-S31 主控与模组选型（Kaleido AI 掌机）
调研日期：2026-10-23 ｜ 调研人：主控选型调研单元

## 结论先行（≤10 行）

1. **推荐方案**：自制 PCB 采用模组 **ESP32-S31-WROOM-3-N16R16V**（16MB Quad Flash + 16MB in-package Octal PSRAM，54 GPIO 全引出，PCB 天线）；固件先行开发直接买 **ESP-Mosaico 开发板（$59）**——其硬件形态与 Kaleido 高度同构（2.16" 480×480 QSPI AMOLED + 音频 Codec + IMU + 磁吸扩展）。置信度：高（官方 datasheet v0.5/v0.7 + 官网价格 + DigiKey 在售）。
2. ESP32-S31 = 双核 RISC-V HP CPU0/1 @320MHz（其中 1 核带 128-bit SIMD 数据通路 + 自定义 AI/DSP 扩展 XespV）+ LP 核 @40MHz，Wi-Fi 6 + BT5.4（LE Audio/经典）+ 802.15.4，全部【官方确认】（datasheet v0.5 §4.1.1、§1 系列）。
3. 项目所需外设全部在片：2×I2S（含硬件级蓝牙音频）+ ASRC、PDM RX（仅"Raw PDM data reception"，硬件抽取滤波**待 TRM 验证**）、GP-SPI2 Quad 模式可驱 QSPI AMOLED、PPA/JPEG/2D-DMA、14 通道触摸、USB 2.0 HS OTG 专用引脚。
4. 引脚预算：**54 GPIO 用约 36 个，余量 ≥18**，I2S/I2C/SPI 均可 GPIO Matrix 任意映射，同时启用全部目标外设**可行**。
5. 模组 vs 裸片：模组贵约 $1–2/片（样例价 $6.2 vs 裸片 $4.4），但免天线设计/免模组级认证风险；ESP-Mosaico 官方自己走裸片路线（NRV16 + 板载 NOR+NAND），量产降本可后期切换。
6. 主要缺口：模组 datasheet 均为 **PRELIMINARY/pre-release**，**模组级 FCC/CE 认证状态未公开**【待验证】；LCSC/立创/淘宝中文渠道**暂未上架** S31 模组（仅有 DigiKey/Mouser/AliExpress 官店），批量国产渠道交期需向代理确认。

### 2. 模组产品线（依据：模组 datasheet v0.5/v0.7 pre-release + 官网产品页）

- **ESP32-S31-WROOM-1 / WROOM-1U**（datasheet Pre-release v0.5）：WROOM-1 板载 PCB 天线，18.0×25.5×3.1 mm，61 引脚；WROOM-1U 天线连接器，18.0×20.5×3.2 mm，64 引脚（多 ANT1/ANT2/GND）。变体：N16R8V / N8R16V / N16R16V / N32R16V / N16R32V（WROOM-1），WROOM-1U 仅 N16R16V。【官方确认】
- **ESP32-S31-WROOM-3 / WROOM-3U**（datasheet Pre-release v0.7，2026-09-03 生成）：WROOM-3 PCB 天线，22.0×30.0×3.5 mm，99 引脚（多排 GND）；WROOM-3U 连接器天线，22.0×24×3.5 mm，仅 N16R16V；ANT2 默认禁用（"To use ANT2, please contact us"）。变体同上 5 种。【官方确认】
- 两系列**均引出同样 54 个 GPIO**（GPIO0–25、33–40、42–61；GPIO26–32 被模组内 Flash 占用，GPIO41 未引出），无 MINI 变体。【官方确认】
- **ESP-Mosaico 官方开发板用的不是模组**：其 CoreBoard V1.2 直接焊**裸片 ESP32-S31NRV16**，板载 16MB SPI NOR（GD25Q128EWIGR）+ 1Gbit SPI NAND（GD5F1GM7UEYIGR，存资源）。（ESP-Mosaico V1.2 用户指南）【官方确认】

### 6. 引脚资源评估（基于模组 datasheet Table 3-1 引脚定义）

可用 GPIO = 54（GPIO0–25、33–40、42–61；GPIO0–7 兼 LP GPIO，深睡唤醒可用）。GPIO Matrix 允许 I2S/I2C/SPI/UART 等数字外设**任意映射**（datasheet §2.3.5、§4.2.2.4 "pins can be chosen from any GPIOs via the GPIO Matrix"）；固定映射仅：USB_DP/DM（专用脚）、ADC（GPIO42–57 差分 N/P）、DAC（GPIO4/5）、触摸（GPIO6–19）、模组内 Flash（GPIO26–32）。

Kaleido 初步分配草案（36 / 54，余 18）：

| 功能块 | 引脚数 | 候选（示意） | 备注 |
|---|---|---|---|
| QSPI AMOLED（GP-SPI2 Quad） | 10 | SCK=IO12、CS=IO10、D/C=IO11、D0–D3=IO13/14/15/16（SPI2_Q/WP/IO4/IO5 复用位）+ RST/TE/BL 任意 GPIO | IO MUX 上 SPI2 信号优先落在 IO9–25 区 |
| PDM 麦（I2S0 RX） | 2 | CLK/DATA 任意（如 IO17/18） | PDM RX 硬件抽取能力待 TRM 确认 |
| 音频 Codec/功放（I2S1 + 控制见 I2C） | 5 | MCLK/BCLK/WS/DOUT/DIN | 如 ES8311（Mosaico 同款） |
| I2C×2 | 4 | 总线 1（IMU+电量计）：IO8/9；总线 2（Codec+功放控制）：IO33/34 之外的普通 IO，或 LP_I2C=IO6/7 | 2 I2C + LP I2C 共 3 组【官方确认】 |
| IMU 中断 | 1 | 任意（如 IO19） | BMI270 INT1 |
| 电池电压 ADC | 1 | IO42（ADC1_CH0_N） | 差分脚单端使用 |
| 按键（方向×4 + A/B + 电源） | 6 | GPIO6–19 触摸通道区或普通 GPIO；BOOT 复用 strapping GPIO60 | 可做电容触摸键 |
| 马达 PWM / RGB LED | 2 | 任意（LEDC/RMT） | |
| 磁吸扩展接口 | 4（GPIO） | 保留 IO43–47 等 + 电源/地 | 预留 UART/SPI 复用 |
| 小计 | **35–36** | — | 余量 ≥18，可再加摄像头（SDIO 2 slot 之一）或 SD 卡 |

注意项：① GPIO36 模组内已上拉、GPIO36/37/60/61 为 strapping，上电电平需按 §3 Boot 配置设计；② GPIO33/34 默认 USB Serial/JTAG（下载/调试口，建议保留）；③ GPIO54–57 默认 JTAG，USB 调试启用后可回收为 GPIO；④ 触摸通道与按键/外设若共用 GPIO6–19 需规划。

**结论：同时启用 2×I2S + PDM + QSPI LCD + I2C×2 + USB + IMU + 功放控制 + 磁吸扩展，GPIO 充足（用量约 2/3），分配可行。**【官方 datasheet 推导】

## 风险与待验证项

| # | 风险/缺口 | 等级 | 验证手段 |
|---|---|---|---|
| 1 | 芯片/模组 datasheet 均为 PRELIMINARY（v0.5/v0.7），参数可能变动；模组 datasheet 无认证章节 | 高 | 向乐鑫/代理索要正式版 datasheet 与 PCN 订阅；锁版前复核 |
