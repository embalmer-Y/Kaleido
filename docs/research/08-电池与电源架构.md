## 结论先行（≤10 行）

1. **电芯**：主推「带保护板（PCM）+NTC 的 605060~656065 高倍率软包，2000–3000mAh，DC 内阻 ≤40mΩ，脉冲 ≥3C（≥6A）」；503450 为薄型基准、806090 为容量上限备选；渠道双轨：立创商城/1688 成品 + 格瑞普（Grepow）定制。置信度：中（需求与拓扑已定，具体型号参数待样测，见 V1/V2）。
2. **充电**：主选 SGM41511（3A 开关型、I2C、JEITA，【官方确认】型号定位，阈值待核 V3）；否决 BQ25185——它是 1A 线性充电器【官方确认】，与"≥2A 充电"需求冲突（任务背景中该假设不成立）；TP4057（竞品同款）无温窗亦否决。置信度：中高。
3. **电量计**：MAX17048 主选，CW2015 降本备选。置信度：中。
4. **USB 供电**：首版 5V/2A（Type-C Rp=3.0A 广播、按 2A 设计）足够；PD（CH224K）预留焊盘不贴——快充收益约缩短 0.5h，中等偏低。置信度：中。
5. **3V3 主轨**：≥2A 高效同步 buck（RT5789 类或国产立创现货为硬条件）；TPS62840/SGM6036 若核实为 600–750mA 级则用作常驻小轨而非主轨。置信度：低-中（候选电流能力全部待核 V4）。
6. **1V8 模拟轨**：3V3 下挂低噪 LDO（AMOLED/codec 模拟域，≤150mA）。置信度：中。
7. **功放轨**：仓库在评 TAS5805M/MA12040P 均 PVDD≥4.5V，**不可电池直挂**【官方确认，本地 PDF】；10W×2 需 12V/2.5A 级 boost（TPS61088 级或国产等效），电池侧脉冲 6–8A → 高倍率电芯 + 大储能电容是硬前提。置信度：中高（boost 计算为本项目推演）。
8. **结构输出**：电池仓深 = 电芯厚 +0.3mm 公差 +2×0.5mm 泡棉：605060 ≥7.3mm、656065 ≥7.8mm；整机 12–14mm 厚度预算下推荐 6.0–6.5mm 电芯。
9. **对标**：ESP-Mosaico 基板电池仅 3.7V/**65mAh**（另售 $15 电池模块，容量未公开）——"容量超越"极易达成；任务背景"约 2000mAh 级"应指其可选模块（【待验证】V6）。

## 2. 电芯选型

### 2.1 需求推导（本项目计算，非引用）

- 功放 boost 方案（10W×2，功放效率 85%、boost 效率 90%）：I_bat = 20W/(0.85×0.90×V_bat) → 3.7V ≈ **7.1A**、3.3V（低电）≈ **7.9A** 峰值（音乐占空比 1/4–1/2，非连续）。
- 功放直挂低压方案（假想 3.7V 器件）：20W/(3.7V×0.98) ≈ **5.5A**（与任务给定一致）。
- Wi-Fi 6 峰值 ~500mA 级（任务给定；ESP32-S31 官方电流表未检索到，【待验证】V5）。
- ⇒ 电芯硬需求：**脉冲 ≥3C（2000–3000mAh → 6–9A）、DC 内阻 ≤40mΩ、带 PCM+NTC 三线引出**。
- 内阻压降核算：7A×80mΩ=0.56V（能量型电芯；恒功率负载下正反馈跌落，不可接受）；7A×35mΩ≈0.25V（可接受，配合储能电容）。

### 2.3 R5 红线落实（安全架构）

- 采用**带保护板成品电芯**：PCM 实现 OVP/UVP/OCP/SCP，优选三线引出 NTC → 满足 R5"独立于主控固件的保护"；
- 主板侧充电 IC 的 JEITA/TS 温窗为第二重保护；
- 【社区经验】经典 PCM（DW01A+8205A 类）阈值典型 OVP≈4.3V / UVP≈2.4V / 两级放电 OCP / 短路保护，**自身不含温度保护**——NTC 必须接充电 IC TS 脚构成完整温控；成品电芯实际阈值随规格书【待验证 V2】。

### 4.3 Wi-Fi 峰值与 brownout 对策

现象链（本项目计算）：Wi-Fi TX 500mA 阶跃（3V3 域瞬态）+ 功放 7A 脉冲 × 电芯 35mΩ ≈ 0.25V（VSYS 跌落）；低电 3.3V 时两者叠加，逼近 buck UVLO 与功放欠压点。

对策（多层，缺一不可）：

1. 电芯 DC 内阻 ≤40mΩ（§2 硬条件）；
2. VSYS 就近储能：2×470µF 低 ESR 聚合物 + 0.1/1/10µF MLCC 阵列；12V 轨 4×220µF@16V；
3. 3V3 buck 选快瞬态拓扑，电源铺铜按 +50% 载流余量（constraints §5.4）；
4. 固件音频功率限幅（AGC/软限幅）仅辅助，不替代任何硬件保护；
5. 电量策略（体验层）：<3.4V 降功放增益档，<3.3V 关功放轨（电量计中断触发）。

### 4.4 给功放专题的接口约束（输出；【官方确认】本地 PDF 直读）

- TAS5805M（TI SLASEH5D，2020-12 修订）：PVDD **4.5–14.5V**（Features）；12V：2×16W@1%THD、2×23W@10%THD（4Ω BTL，Table 2）；**5V 仅 2×5.5W@10%**。

## 6. 电池安全与结构要求（输出给 kaleido-mech）

1. **固定**：电芯仓四周 0.5mm 阻燃泡棉，预压缩 10–15%；严禁硬物压极耳与气袋面（铝塑膜变形→绝缘击穿风险）【社区经验，随 V10 验证】。
2. **NTC 贴位**：NTC 焊于极耳侧（发热最大区），导热泡棉压合贴壳内表面；TS 走线远离功放大电流区。
3. **防爆阀朝向**：软包气袋边朝向壳体泄压间隙，不被 PCB/泡棉封死。
4. **尺寸链输出**：电池仓深 = 电芯厚 + 0.3mm 装配公差 + 2×0.5mm 泡棉 → 503450 ≥6.3mm、605060 ≥7.3mm、656065 ≥7.8mm、805080 ≥9.3mm（均不含 PCB/屏/壳壁）。整机 12–14mm 厚度预算 → 推荐 6.0–6.5mm 电芯；板面积富余且厚度放宽时，806090（8mm）为容量上限方案。
5. **最热场景**：2A 充电 + 边玩边充（功放+Wi-Fi 同开）——JEITA 温窗与 NTC 位置须覆盖（V7 热测验证）。
6. **运输/仓储**：成品出货电量 30%±10%；电芯入厂核 UN38.3 报告；仓储 0–35℃、30–60%RH【社区常识，写入产线 SOP；正式依据随 V8 落实】。
