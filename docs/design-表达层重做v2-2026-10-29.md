# 表达层重做 v2 — 详细设计（2026-10-29；屏到即执行）

> 依据：表达层拆除与重做-2026-10-28.md（教训与拆除基线）、V-48b
> 旧门禁、V-45 内存工程结论、缺陷 L/M 纪律。目标：今晚屏到货后
> **只执行不再设计**——本文档含全部决策点、按屏规格的分档方案、
> bring-up 顺序与新门禁判据草案。负责人未拍板的开放项集中在 §0/§3。

## 0. 设计立场（三条根决策，负责人今晚可推翻）

1. **参数化猫脸，不是预制片段库**。旧版"22 段 GIF 感片段+映射表"
   被评"不满意"的根因是片段语义离散、动画僵、观感廉价。v2 改为
   **程序化参数化表情**：猫脸=图元（眼/嘴/耳/头姿/底色）的连续
   参数组合，"活"感来自微动（自主眨眼/呼吸/瞳孔漂移），不是切换。
   emote_gen 分区与 5.3MB 表情包**不复用**（保留分区不删，无害）。
2. **不用 LVGL**。旧版三教训全与 LVGL 相关（默认屏露出=淡蓝闪屏
   假设①、32K 任务栈、与音频竞态互锁）；2 寸屏分辨率小、UI 需求
   单纯（OOBE 配置已走 web V-42），自绘裸 framebuffer 更可控、
   免掉 LVGL 全套内存与任务。若负责人想要屏上富 UI（天气/时钟
   卡片）再议——那是"仪表盘"不是"猫脸"，可后置。
3. **逻辑层 panel-agnostic，host-first**。表情状态机（九维→参数
   目标→动画）是纯函数模块，主机单测全绿后才上板；板上只有
   "参数→像素"渲染器 + 面板驱动两个薄层。今晚屏规格未知的部分
   全部隔离在驱动适配层（§4 决策矩阵）。

## 1. 架构（自上而下单向，纪律不变）

```
soul tick 1Hz ──→ expr_target（九维快照→参数目标，纯函数）
事件脉冲(快路径) ─→ expr_event（wake/barge/round/speaking，≤1 帧）
                    │  深度 4 队列（满则丢旧——表情永远追最新）
                    ▼
expr 任务 20-30fps（内部栈 6KB，只碰 PSRAM，禁 flash 写）
  ├─ 目标插值：每参数独立 slew/缓动（无片段驻留概念，天然无抖动）
  ├─ 自主微动层：眨眼 SM/呼吸相位/瞳孔漂移（与时钟无关的伪随机）
  ├─ 说话包络：参考环 20ms 能量→mouth.openness（audio-reactive）
  ▼
frame 描述（参数全量快照）→ 渲染器（图元→RGB565 行缓冲）
  ▼
panel 适配（SPI/QSPI/DSI 三档之一，§4）→ 屏
```

- **单向通道纪律**（V-48b 教训）：soul→expr 只发九维快照与事件，
  表情层永不回写情绪数值；expr_target 失败/队列空→保持当前目标
  （表情是"显示器"不是"传感器"）。
- **板级纪律**（缺陷 L/M/V-48b 教训）：expr 任务静态内部栈；渲染
  只写 PSRAM FB；DMA 描述符走内部；与音频的竞态面=零共享（参考
  环只读）。

## 2. 表情状态机（纯函数层，host 可测）

### 2.1 参数空间（一次定全，渲染只认这套）

| 组 | 参数 | 域 | 驱动来源 |
|---|---|---|---|
| eye | openness_l/r | 0..1 | 情绪目标+眨眼 SM 叠加 |
| eye | gaze_x/gaze_y | −1..1 | arousal/urgency/thinking 姿态 |
| eye | pupil | 0.6..1.4 | valence（正=放大）+刺激脉冲 |
| mouth | curve | −1..1 | valence 主通道 |
| mouth | openness | 0..1 | 说话包络（说话期）；情绪副通道 |
| ear | perk_l/r | 0..1 | social 驱力/事件（wake→1） |
| head | tilt | −1..1 | 情绪 tag 低频摆动 |
| body | breath | 0..1 相位 | 自主微动（arousal 调频率） |
| base | tint_warm | 0..1 | valence→暖/冷底色混合 |
| state | doze | 0..1 | 睡眠深度（旧 asleep 判据迁移） |

### 2.2 九维→目标映射（v1 表，HIL 注入可调）

- `valence` → curve（线性，±0.15 死区=平静微正）、tint_warm
- `arousal` → gaze 活度/blink 频率/breath 频率/openness 基线
- `urgency` ≥0.5 → openness 基线抬升+gaze 锐度
- `ethics_latched` → 柔和低垂（openness↓ curve 轻正 tilt↓）——安抚态
- `social` 驱力告警 → ear perk↑ + gaze 寻人（扫视）
- `rest` 告警 HIGH + 安静 600 拍 → doze 斜坡（沿旧 asleep_215s 语义）
- `novelty/surprise`（W6b 接入前=0）→ 瞳孔脉冲
- KI 结算态（IGNORED→curves 轻垂；RESPONDED→bounce 一次）
- 会话四态叠加（优先级高于情绪底色，同旧 KEX 桥）：
  LISTENING→侧耳+睁大；THINKING→gaze 上移+眨眼变频；SPEAKING→
  mouth 包络主导；IDLE→情绪底色。

### 2.3 事件快路径（绕过 1Hz，≤1 帧生效）

wake→ear 双耳 perk+瞳孔放大 1.5s 衰减；barge→surprise 瞬态
（openness 1.0+curve −0.3，1.5s 回落）；round 结算→响应曲线
（RESPONDED 微笑脉冲/ROUND_FAIL 轻垂）。事件在 expr 任务内做
**瞬态叠加**（不修改 1Hz 目标，衰减后自动回底色）——旧版"活动
四态优先级"问题的结构性解法。

### 2.4 插值与防抖

每参数独立一阶惯性：`p += (target − p) × dt/τ_p`，τ 按语义分档
（眼动 80ms/情绪底色 2-4s/doze 30s）。旧版"最短驻留 8 拍+同片段
不重切"三件套由 τ 分档天然替代——参数连续即无抖动，无需判据。
滞回不需要（无离散切换）；ke_hysteresis 的 P0-1 修复与本层无关。

## 3. 渲染器（图元层，两档分辨率方案）

猫脸图元集（全部 2D 基础图元，无依赖库）：
- 脸底盘=圆/超椭圆（tint 两色插值填充）
- 眼=椭圆×2（openness 压扁；瞳孔=内圆，gaze 偏移；高光点）
- 耳=三角形/贝塞尔×2（perk 抬角）
- 嘴=二次贝塞尔（curve 控制点上下移，openness 开口）
- 腮红/斑纹=软圆（可选装饰，负责人观感拍板）
- 状态角标（可选）：唤醒/联网/静音 8×8 图标位（自绘位图字库）

实现策略按屏分辨率二选一：
- **≤320×320（档 A，SPI 小圆屏 GC9A01 类）**：单帧全绘。帧预算
  240×240 RGB565=112.5KB PSRAM；整帧填充+窗口 DMA 写。CPU 估
  <10ms/帧（简单图元+定点/单精度混算）→ 30fps 富余。
- **≥400×400（档 B，QSPI AMOLED SH8601/RM67162 类）**：分层合成。
  底盘/斑纹静态层缓存 PSRAM，动层（眼嘴耳）脏区重绘+窗口写；
  帧预算 480×480 全绘约 40-60ms → 脏区策略保 20fps。
- DSI（若 2 寸仍是 DSI 小长条）沿用 dsi-lvgl 工程裸 DPI 路径，
  渲染策略同档 B。

CJK 字（状态行"我在听…/思考中"等）：8×8/12×12 点阵自建小字库
（仅表情所需 ~60 字，工具链离线生成 C 数组），不走 LVGL 字体引擎。

## 4. 面板适配层（今晚 Phase 0 拍板的决策矩阵）

| 屏规格 | 接口 | 驱动骨架 | 关键风险 |
|---|---|---|---|
| GC9A01 240×240 圆 | SPI+DC/CS/RST | esp_lcd_spi 通用面板（GC 系已有 panel GC9A01 组件生态） | 帧率=SPI 时钟上限（40-80MHz 实测定） |
| SH8601/RM67162 410/480 圆 AMOLED | QSPI | esp_lcd 面板+厂商 init 序列（mipi-qspi 桥） | QSPI 时序+电源（VCI/复位时序） |
| ST7789 240×320 方 | SPI | 同 GC9A01 路径 | 无圆 mask，脸形改方内切 |
| 小 DSI 条屏 | MIPI-DSI | dsi-lvgl 工程改造+新 IC 时序表 | DSI LP-HS（淡蓝闪屏假设②在此档复活） |

Phase 0 清单（开箱 15 分钟）：接口线序确认→供电/背光（或自发光）→
控制器 IC 识别（丝印/规格书）→分辨率/色深→**回报负责人拍板渲染档**。
电源注意：AMOLED VCI 3.3V 与 QSPI 电平；SPI 屏背光 PWM 脚复用查询
（防与触摸/audio 冲突，korvo1-板级事实.md 对照）。

## 5. bring-up 顺序（当晚执行单，半小时粒度）

1. **Phase 0 规格确认**（上表）→ 决定适配分支。
2. **Phase 1 独立点屏**：新工程 `tools/hil/panel-2in`（从 dsi-lvgl
   复制骨架剥离 DSI 部分）——清屏纯色→彩条→局部窗口写→刷新率
   实测（逻辑分析仪口径或帧计数）。电源时序严格按规格书（AMOLED
   复位≥指定 ms）。
3. **Phase 2 表情状态机 host-first**（其实可今天先写，见 §7）——
   主机注入九维序列跑映射+插值全轨迹单测。
4. **Phase 3 并回 convo-stage**：初始化次序铁律（V-45）：aio（I2S
   DMA）→ panel → wifi 最后；背光渐进淡入（0→工作亮度 2s，防夜
   间刺眼+电流冲击）；静态内部栈；READY 菜单加 'e' 表情自检键
   （注入序列回放，替代旧轮播）。
5. **Phase 4 事件+包络**：wake/barge 快路径接 wakenet_test 钩子
   （已有 soul_on_voice/barge 同点）；mouth 包络从参考环取
   （aio_ref_get，注意缺陷 L 修复后的正确用法照抄）。
6. **Phase 5 V-48b v2 门禁**（§6 判据）+ **淡蓝闪屏专项**：新屏
   非 DSI 则假设②自动排除；仍复现→假设①③按拆除文档序排查
   （首查屏切换/GRAM 毛刺，因 LVGL 已不在链上，假设①也随之收窄）。

## 6. V-48b v2 门禁判据草案（参数级，替代片段判据）

① **映射一致性**：注入 valence/arousal 阶跃 → 遥测 `VL,EXPR,
v=?,a=?,eye=?,mouth=?,ear=?,doze=?` 与映射表逐拍一致（1Hz 快照
对账）。
② **插值连续性**：任意参数相邻 1s 步进 ≤τ_p 对应上界，无跳变
（连续性判据替代旧"驻留≥8s"）。
③ **事件快路径延迟**：wake 注入→ear perk 起始 ≤50ms（expr 任务
帧间隔口径）；瞬态 1.5s 后自动回落底色（无残留）。
④ **说话包络相关**：SPEAKING 期 mouth.openness 与参考环 RMS 的
   相关系数 >0.5（soak 内板端统计，现有 DBGVOL 仪表复用）。
⑤ **帧预算**：满载 soak（语音并发）下帧渲染 P95 ≤20ms（档 A）/
   脏区 ≤30ms（档 B），掉帧率 <1%。
⑥ **闪屏专项**：连续 2h soak 零异常帧（帧头 CRC 探针+人工观察
   双口径；新屏 DSI 档才全跑）。
⑦ **内存底线**：并回后 PSRAM 空闲降幅=FB 实际占用±5%；内部空闲
   降幅 <8KB（DMA+栈）；soak 无内存劣化趋势。
⑧ 肉眼观感（负责人）：眨眼/呼吸自然度、说话嘴动同步、睡眠态——
   仪器判据全绿后目验收口。
