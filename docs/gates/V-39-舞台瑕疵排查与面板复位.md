# V-39 角色舞台瑕疵排查与面板复位（2026-10-26）

## 背景

17a49862（30fps 三缓冲邮箱舞台）目视反馈：彩块重影 + 全屏高竖向错位色条。
54cd50ab 后反馈：竖条仍在 + 高频微闪。最终：肉眼全净、验收通过。

## 结论（按发现顺序）

| # | 现象 | 根因 | 修复 |
|---|------|------|------|
| 1 | 彩色碎块重影 | ThorVG 从不清 swcanvas 目标缓冲，移动元素旧像素永久残留（离屏基准只算校验和从未暴露） | 每帧渲染前 memset（54cd50ab） |
| 2 | 持续竖条 + 高频微闪 | **面板陈旧状态**：`LCD_RST=-1`，静默 HW-WDT 热重启只复位 SoC 不复位面板；坏状态留屏直到断电 | `LCD_RST=GPIO5`，每次启动硬复位面板 |
| 3 | ~5s 一闪的三条淡竖条 | 自带 FBDIFF 诊断（LVGL 定时器内 4MB memcmp 突发）把 PSRAM 带宽压到 DSI 容忍边缘（无 underrun 中断、肉眼极淡） | 删除诊断块 |
| 4 | 相机可拍的闪现竖条 | 卷帘快门 × 60Hz 刷新拍频混叠，眼睛不可见 | 无需修复（预期物理） |

## 关键证据链（供复用）

- fb 内存逐点校验：背景 0x10C5 全净、双 fb 差异始终限于舞台 bbox → 排除合成层
- DSI UNDERRUN 中断 0 次（含 FBDIFF 突发期间）→ 排除 FIFO 见底
- 185s 连续：render 27/s、disp 30/s、skip=0、cb 31ms 稳定 → 排除管线退化
- 8s 动画/8s 冻结自动循环 + 目视矩阵：两种状态全净 → 锁定"看屏时板子坏着"
- rst:0x7 (HP_SYS_HP_WDT_RESET) 出现于串口开口复位后：开口→复位→偶发启动早期挂死→HW WDT 二次启动（B-2 类）；"STAT 变少/时间退化"假象皆源于此

## 沉淀

1. **热重启不碰面板 = 玻璃残留假象**：任何"显示突然持续异常"先查板子是否静默重启过（看串口 rst 原因），再怀疑渲染路径
2. 串口工具每次开口都可能复位板子（CH343 枚举/DTR 舞蹈）；遥测窗口若 STAT 变稀，先怀疑重启吃了窗口
3. LVGL direct 模式双 fb 的 sync_areas 机制逐行核实为每帧清空、收敛正确（排除项）
4. 留用工具：`f` 冻结 / `d` 双 fb 探针转储（串口 RX 偶发不响应，跨启动不稳定，勿依赖）；cb/loop 节奏遥测
5. 相机验收不作准（混叠），以肉眼为准
