# V-04 唤醒词真机实测结果（2026-10-25）

| 项 | 结果 |
|---|---|
| 平台 | ESP32-S31-Korvo-1 V1.1（2×模拟麦 → ES8389 → I2S0，16kHz/双声道） |
| 软件栈 | ESP-IDF v6.1(esp32s31 preview) + esp-sr 2.6.0 + esp_codec_dev 1.6.2 + **wn10_hilexin_int16** 模型 |
| 测试方式 | 真人语音：正常音量 ×10（30-50cm）+ 远距离 ×3（~2m），穿插闲聊测误触发 |

## 结论：✅ 通过

- **检出率 13/13 = 100%**（含 3 次远距离，最弱一次 -61.7 dBFS 仍检出）
- **误触发 0**（4 分半窗口含闲聊，17 个心跳期间 det 稳定不涨）
- **内存**：整条语音链（AFE SE(BSS)+VAD+WakeNet10 int16 + codec + I2S DMA）峰值占用 ~1.3MB，空闲堆稳定 15.85MB（16MB PSRAM）
- **稳定性**：分片续读 + DMA 自愈补丁后全程零断流、零内核错误

## 调试过程中确立的 S31 关键事实（工程黄金数据）

1. **W-5（上游缺陷，已绕过）**：esp-sr 2.6.0 在 esp32s31 上——
   - wn9s 系列模型（Kconfig 允许 S31）**无法挂入 AFE 管线**（自动挂载静默缺失，`add_wakenet_model` 显式挂载返回 -1）；
   - wn10 q8p2 量化模型可挂载但**推理报 `Conv: no Conv kernel for packed key 0x0302`**（esp-dl S31 缺该量化卷积内核）；
   - **唯一可用路径 = wn10 int16 模型**（`SR_WN_WN10_HILEXIN_INT16`，唤醒词"Hi,乐鑫"）。
2. **采集健壮性**：int16 推理负载下 I2S 读取可能出现连续部分超时（一轮测试 6506 次）——分片续读+超时重启 DMA 通道后彻底解决（后续多轮零复发）。
3. 增益标定：ES8389 in_gain=42dB 会削顶（大声语音峰值打满 32768），**24dB 为安全值**（语音峰值 ~2000-3000，底噪 ~400）。
4. 检测阈值 0.60（诊断期放宽值）实测无虚警；正式参数待量产标定。
5. 附带实证：S31 封装内 PSRAM = 16MB Octal @200MHz（vendor 0x1a），内存自检通过。
