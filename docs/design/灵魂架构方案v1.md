## §0 结论先行

1. **六个子系统可落在 S31 上，无需换芯片——前提是关闭 PSRAM XIP（预算表 v2 结论）**：esp-claw 默认 `SPIRAM_XIP_FROM_PSRAM=y`，**镜像占 4,077KB → 可分配池实为 12,306KB（V-32 A 级实测，非 16,384KB）**。按 12.3MB 池、并入表达子系统 2.4MB（25 号 §4.5）与 V-32 修正重算（预算表 v2 见 §5）：**XIP on 保守总计超池 ~0.8-1.4MB，裁剪无法在"质量优先"下补齐 → 关 XIP（回 flash 执行）是算术上唯一完整路径**，其 CPU/帧率代价由 **V-35 与 V-34 同场交叉压测**定量（关 XIP 后池回到 16,384KB，保守总计 13.7MB，余 ~2.7MB）。**XIP 取舍是 M1.5/M1.6 的前置门（评审阻断项裁决）**。esp-claw 基座实测 1.6-2.2MB（好于原估，不确定度 ±1.5MB→±0.3MB）。Flash 双 4.5MB OTA 槽可管理；唯一临界 CPU 场景是全屏 Lottie（判死），对策为动画分级 T0/T1/T2（20 号 §6.3）。
2. **语音链路**：云 ASR+TTS 全 BYOK，**首推阿里百炼**（key 直用零签名 + 免费音色复刻 10-20s + 双向流式 WS + 1-1.5 元/万字符最低档），架构按"**组合 C**"实现：固件抽象 `speech_provider` 接口（百炼直连 + 自托管 WS 网关两个实现），火山豆包为第二云预留。首响应 <1.5s 需"流式 ASR + 首句即送 TTS + 唤醒期预热连接"组合达成（19 号 §4.4）。
3. **情感 = Galatea L05 提取**：九维感受态确定性动力学（~1201 行 Python → 800-1200 行 C），LLM 禁直写情感、有界调制 + TTL + 回执的安全范式整体继承（18 号）。
4. **点火 = 两阶段**：**方案 A 先行**（本地多因子打分器 + 滞回 + 冷静期 → 一次云 LLM"该不该说+说什么"裁决；2-3 周），日志 schema 预留 B 字段；**方案 B 演进**（G2/G3）已升级为 **Galatea 真实结构**：驱力(L05 drives)→九源动机→**Pareto 支配仲裁**（非加权和）→ C-5 防"用户指令/LLM 劫持"→ 慢环"意图孵化器"（四拍思维循环，云 LLM 只占 evaluate 插件与话术生成两个接缝）→ metacontrol 滞回状态机（24 号 §6）。内核 1200-1600 行 C，离线全可降级（Moxie 变砖教训）。
5. **"jev" 考证**：大概率指 **TypeSafe AI 2026-09-15 发布的 Jev 决策模型**（云端 API，输入状态→类型化决策+校准概率，70-500ms，$0.042/MTok，early access）——与负责人"决策模型"措辞吻合；次选 JEPA（世界模型，学界不称决策模型）。**裁决建议：借 Jev 的"形态"（便宜快速的类型化裁决层），不绑其服务**（供应商/early-access 风险）；方案 A 的云裁决调用就是其无供应商复刻，接口 `/ignite` 收敛一处，日后可无缝换 Jev API。**待负责人一句话确认（§6 D-7-1）**。
6. **表达 = 三层混合管线**：分层 PNG 骨架（常驻呼吸/眨眼/口型，CPU <10%）+ EAF 帧序列全屏情绪 20fps（JPEG 硬解）+ Lottie(ThorVG) 限 ≤230×230 小窗与限时高光。情感驱动：LLM 句级内联 `[tag]`（主）+ 整轮 emotion JSON（兜底），设备端 23 词表多对一映射 8-10 基础情绪；口型由 TTS 音频能量本地驱动（20 号 §4.2）。esp_emote_expression **借架构不集成**（25 号 §4.2）。
7. **角色 = .kpersona 纯数据包**：persona.json（人设卡+音色绑定+动画资产索引+情感参数档+点火风格+记忆初始化）+ 分发基建复用 KApp 扫描/侧载（模型层独立，全局单激活）。创建三路径：语音访谈式（主打差异化）→ 网页工坊精修 → 二期 App（25 号 §3）。
8. **记忆 = NAND 内建，SD 卡不进 v1 BOM**：LittleFS + 三层 JSONL（core/episodic/raw）+ 本地 tag/时间初筛 + 云端 embedding BYOK 精排（float16 向量缓存回 NAND）；备份 = USB-C MSC（esp_tinyusb v3.0.0 已支持 S31）+ 局域网网页 + 可选云推送，统一 seq 版本化备份包，可选 AES-256-GCM 加密。SD 卡座以 **DNP 焊盘 + GPIO20-25"存储保留段"零成本预留**，G2 引脚表冻结时终裁（21 号 §6）。**关键新事实：S31 SDMMC 只能用 IO MUX 专用脚（GPIO20-25/35-40），且全配引脚余量修正后仅 0-2 脚**。
9. **感官管线 = 复用 esp-claw 原生 MCP**：App 能力 = 注册 claw_cap（自动成 MCP tool）；App 感官数据 = 新组件 `kaleido_sensor_bus`（claw_event_router 扩展，500Hz→聚合≤1Hz）+ MCP resource 原语包装（mcp-c-sdk 2.0.1 已有 resource，cap 层未包装——kaleido 补一层，零侵入）；权限闸 = `claw_cap_set_llm_authorizer` 挂 KApp 8 类权限位图；隐私 = 本地摘要 ≤500 token/轮，private 级数据不进云（23 号 §4）。
10. **实施总量**：固件新增 8 个组件（§2），一期（=对话链路+角色+表达+记忆+点火 A）约 **95-130 人日**（含美术 10-14 人日）；美术资产与工具链无固件依赖可立即启动。

## §2 组件架构（在 kaleido-claw 五层之上）

```text
KShell ── kaleido_express（角色舞台：四层动画状态机 + 口型 + 情绪映射）   ← UI 原生舞台，非 KApp
KApp 框架 ── kpersona 注册表（.kpersona 数据包；扫描/侧载基建复用 KApp）
Claw 核心 ── speech_provider（ASR/TTS 抽象：dashscope / selfhosted-gw）
         ── kaleido_soul（灵魂内核，全部本地 1Hz 拍 + 事件驱动）：
              kaleido_drive    驱力内稳态（L05 drives 范本）
              kaleido_emotion  九维感受态动力学（L05 affect）
              kaleido_ignition 九源动机→Pareto 仲裁→慢环孵化→metacontrol 状态机（L07/L08）
              kaleido_memory   三层记忆 + 索引 + 备份（本地存储与检索编排）
              kaleido_sensor_bus 感官总线（App/传感器→聚合→情感/点火/LLM 上下文）
BSP ── 音频链扩展（ASR 采集/预滚窗、TTS 流播放队列）；NAND 分区（littlefs memory + fatfs share）
服务端（开源附件，可选）── 自托管语音网关（FunASR+CosyVoice3 docker-compose）
```

**灵魂内核数据流（方案 B 全景，方案 A 为其退化子集）**：

```text
[感官] IMU/VAD/时钟/App传感器 ─▶ sensor_bus 聚合(≤1Hz) ─┬─▶ drive（内稳态误差：无互动时长/电量/新事件率）
                                                        ├─▶ emotion（九维 1Hz；novelty/uncertainty 亦由感官误差供给）
                                                        ├─▶ 上下文注入器（≤500 tok 进 prompt）
                                                        └─▶ memory（事件写入与检索触发）
[情感环] drive 误差 ─▶ emotion（valence/urgency 等积分）─▶ affective_motive {urgency, evidence}
        emotion(reappraisal 受控通道) ◀─ 云 LLM 有界提案（禁直写）
[动机] drive告警(VIABILITY)/情感urgency(AFFECTIVE)/用户消息(REQUEST,恒0.5)/到期承诺(COMMITMENT)/
       好奇心(CURIOSITY)/SELF_REPORT分箱冲动/慢环草稿(SLOWLOOP)
   ─▶ kaleido_ignition：C-5 清单 → Pareto front → 优先序 tie-break → 单胜者
[慢环] 空闲(idle)或低唤起(arousal<0.1，读 emotion) ─▶ 草稿板孵化(四拍循环,预算8步,种子=memory Top-3+分箱变化+日程) ─▶ 回流动机竞争
[执行] 胜者过防骚扰门(勿扰/冷静期/配额/上下文门) ─▶ 云 LLM 裁决+生成{speak,line} ─▶ speech(TTS hint 查表) + express(动画 hint 查表)
[回填] 用户回应/忽略 = 结算证据 ─▶ drive/emotion 回填（social_bond 正向/忽略冷却）+ 点火日志（winner_source/vector[5]/dropped[]）
```

## §3 语音链路（需求 1）

- **选型**：百炼 Paraformer/fun-asr-realtime（WS 流式）+ CosyVoice-v3.5/qwen-tts-realtime（双向流式 WS，服务端自动分句）+ voice-enrollment 复刻（免费，10-20s）；LLM 沿用 OpenAI 兼容 BYOK。备选第二云：火山（音质标杆，复刻 7000 元/音色不用于用户自助）。
- **`speech_provider` 抽象**：`sp_asr_open()/feed_pcm()/final_text()` + `sp_tts_open()/feed_text()/pull_pcm()`，两实现（dashscope 直连 / 自托管网关 `wss://...`）；百炼 pcm 直出待实测（R2，不行退 mp3 走 vendor 已有 esp_audio_codec 解码）。
- **延迟预算**：VAD 尾长 300ms + ASR 尾句 100-400ms + LLM 首 token 300-800ms + TTS 首包 150-500ms + 网络/起播 200ms ≈ **1.05-2.5s**；<1.5s 需六条件组合（19 号 §4.4），对外承诺口径建议 1.5-2.5s。**V-32 附带发现：当前 edge_agent LLM 调用为非流式，端到端 9.7-18s——M1.5 必须改流式 SSE + 首句即送 TTS，这是语音链路的硬前提**。
- **TLS**：PC 端握手矩阵已测 4 端点双版本全通（19 号附录 B）；真机 mbedTLS 复测 + 设备 CA 链核对列 G2。
- **月成本全口径（用户视角，产品评审补）**：需配 **2 把 key**（LLM 一把 + 百炼一把，后者兼 ASR/TTS/复刻）。全口径 = LLM 对话（月 2-70 元，BYOK 模型决定）+ ASR（~4 元/5h）+ TTS（30-45 元/30 万字）+ embedding（<$0.2）+ 点火裁决（<$0.3）；轻/中/重三档估 **约 15 / 40-80 / 150+ 元/月**（自托管≈电费）。设置页用量可视化 + 配额/欠费自动降级（§9）；百炼新用户免费额度待核验（V-33 顺带）。

## §5 S31 判定与资源红线（需求 6）

- **Flash**：双 4.5MB OTA 槽的前提是固件 ≤4.5MB（现 4.07MB，需裁 UVC/HLS 等未用组件）；动画资产/字体大头下沉 NAND。
- **CPU**：核分配 CORE0=通信/agent/ASR-TTS，CORE1=LVGL/EAF/WakeNet；动画分级 T0（骨架，稳）/T1（对话 EAF 全屏+骨架口型，可行）/T2（高光，Lottie 限时+降级并发）。**V-34×V-35 交叉设计（评审严重项）**：同一压测工程、同场跑 XIP on/off × 动画档位（T0/T1/T2）× 唤醒并发，一次取齐 CPU/帧率/heap/首响延迟四组数据，避免两次压测口径不可比。
- **灵魂内核测试策略（评审严重项补齐）**：drive/emotion/ignition 三件为**纯函数式确定性模块**（零 RNG/零墙钟）→ ①Unity 单测覆盖每条公式与状态机迁移；②**黄金轨迹回归**：冻结输入序列（拍数×事件流）→ 断言全状态逐拍快照（Galatea 821 测试同款方法论）；③参数全部 `static const` 冻结表 + 扫参仿真脚本（点火"闷/烦"二维扫描，上线前跑）；④慢环/仲裁以日志 schema（winner_source/vector[5]/dropped[]）做端到端可观测性验收。
- **Flash**：双 4.5MB OTA 槽的前提是固件 ≤4.5MB（现 4.07MB，需裁 UVC/HLS 等未用组件）；动画资产/字体大头下沉 NAND。
- **CPU**：核分配 CORE0=通信/agent/ASR-TTS，CORE1=LVGL/ThorVG/WakeNet；动画分级 T0（骨架，稳）/T1（对话 EAF 半屏 Lottie，可行）/T2（高光全屏限时+降级并发）。
- **双轨更新**：17 号三触发条件均未触发；**新增激活条件 ④**：G2 动画压测（V-34×V-35）实测 T1 态单核 >85% 且优化后仍不达"对话表情流畅"验收线，或 **V-35 证明关 XIP 后的系统代价（帧率/CPU/首响延迟）不可接受且无其他池内收敛路径** → 提请 R1 变更评估（P4+C5）。
- **质量优先的含义**：不裁体验换资源，而是**用架构纪律换资源**（分级/下沉/仲裁）；若纪律用尽仍不达标才换芯片。

## §10 合规与内容安全（产品评审阻断项 H1 补齐）

- **项目立场（D-7-10）**：开源工具、无默认云服务、无账号体系、纯 BYOK——内容服务责任归云厂商；Kaleido 承担设备端兜底义务。
- **内容兜底三件（固件级）**：① TTS 前本地敏感内容门（拦截→安抚模板，与 ethics_latched 联动）；② 复刻显著标识（克隆音色首播提示 + "复刻他人声音须获授权"法律文案进复刻流程）；③ 年龄建议（12+/家长指引）+ 新机首周"克制模式"（点火默认关，渐进放开）。
- **隐私四件（G2 引脚冻结强相关）**：首次开机一页式声明 + 逐项开关；**云 embedding 首刷批量出云显式同意**（记忆上云可关=退本地初筛）；备份**默认口令加密**（修正 21 号"默认不加密"）；**麦克风硬件静音开关或 LED 进 G2 引脚冻结议程**（余量 0-2 脚，与 SD 保留段同场裁决）。
- **防依赖设计**：主动度旋钮一键"太黏了"降档；使用强度提示（可选）；负反馈只学时机不学内容（防养歪）；ethics_latched 阈值重推导列负责人裁决，闩锁屏显形态待规格。
