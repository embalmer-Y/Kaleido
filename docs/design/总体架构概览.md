**产品定义（2026-10-24 负责人定稿）**：设备为**平台型 AI 桌搭**——裸机只带屏幕/摄像头/麦克风，**不做功能预设**；出厂默认 = AI 日常对话 + Claw 写 App 能力；一切具体功能由用户通过 App、顶部扩展、底部底座自定义实现。

## 1. 产品一句话

**基于 ESP32-S31 的开源智能桌搭 AI 伴侣**：摆在桌面上的小型设备，AMOLED 屏幕 + 双喇叭 + 双麦克风阵列，语音对话（离线唤醒 + 云端大模型）、拍照/视觉、可写 App 的 Claw agent、可接 Muse 生态；顶部/底部磁吸扩展传感器与底座执行器；体验对标并超越乐鑫 ESP-Mosaico，成本低于其售价。

**形态**：智能桌搭（非掌机）。静态摆放 + 语音/触摸交互为主；物理交互（按键/摇杆/云台）由扩展配件承担。

## 3. 硬件架构要点（G1 推荐，G2 冻结前仍可调）

| 域 | 方案 | 关键判断 |
|---|---|---|
| 主控 | ESP32-S31-WROOM-3-N16R16V 模组 | 54 GPIO；全外设+摄像头后余量仅 4–5 脚 → **G2 必须冻结引脚表** |
| 显示 | 鱼鹰 OSPTEK AM200Q460460FLS1（2.0" 460×460 QSPI AMOLED+触摸） | 乐鑫官方 esp_lcd 组件；QSPI 50MHz → UI 30–60fps |
| 语音输入 | 2× 敏芯 MSM261DDB031 PDM 麦 → S31 I2S0 直采 | 全数字，无模拟走线；esp-sr AFE/WakeNet |
| 语音输出 | S31 I2S1 → TAS5805M（esp_codec_dev v2.0 驱动）→ 2× 喇叭 | **无 codec**（全数字链路）；耳机走 USB-C 数字音频 |
| 喇叭/声学 | 2× Same Sky CMS-2594-24SP（Ø25mm 4Ω 3W，T/S 公开）+ 密闭箱 10–15cm³/声道 | **功率诚实口径：峰值 2×10W 级（12V 轨瞬态）、连续 3–5W×2**；倒相箱不可行 |
| 功放电源 | 12V/2.5A 升压轨（≥30W）；电池脉冲 6–8A | 所有 ≥10W 级 I2S 功放均不可电池直挂（PVDD≥4.5V） |
| 电池 | 605060~656065 高倍率软包 2000–3000mAh，PCM(OVP/UVP/OCP/SCP)+NTC | 桌搭形态体积放宽 → 偏上限取容量；R5 安全红线 |
| 充电/电量 | SGM41511（3A 开关型、JEITA）+ MAX17048 电量计 | USB-C 5V/3A 首版足够，PD 仅预留焊盘 |
| 摄像头 | OV2640（2MP DVP，片上 JPEG）板载 + 物理遮挡拨片 | esp_cam_sensor+esp_video 新栈（旧 esp32-camera 不支持 S31）；**无 TF 卡，拍照存 NAND** |
| 扩展 | 顶部 POGO（传感器/摄像头）+ 底部 DOCK（舵机云台，底座自带供电） | I2C 协议 + EEPROM ID；三类配件：input/sensor/actuator |
| IMU/振动 | BMI270（硬件手势引擎）+ AW86224+LRA（v1 板兼容 ERM 布局） | 桌搭下 IMU 用途收窄为翻转静音/姿态感知 |
| 结构件 | 打样 FDM→SLA→MJF；1k 台注塑 V-0 阻燃 PC/ABS | 桌搭形态 envelope 待 V-14 按新形态输出 |
| 成本 | BOM 红线 ≤$55（1k 台）；工作预算 $50；当前估算 $32–54（含摄像头） | 敏感项：结构件（产量敏感）> AMOLED > 模组 |

## 4. 软件架构要点（Kaleido-Claw，M0 已构建通过）

```text
KShell        自研 UI：LVGL9 + PPA 2D 加速 + JPEG 硬解；设计 token 单源；主屏 App 网格
KApp 框架     manifest(JSON)+8 类权限位图+生命周期；崩溃 2 次自动禁用（回滚保护）；
              无签名鉴权（仅来源标记）；一期运行时 = esp-claw 原生 Lua，二期评估 wasm
Claw 核心     fork 自 esp-claw(9b23c15)：agent loop / LLM / MCP client+server / skill /
              结构化记忆；「AI 写软件」= chat coding 生成 Lua+manifest → 确认安装为 App
Muse Link     包裹 muse-gadget-sdk(c9354b7)：对话/avatar/视频流；编译期可插拔
              （tinyh264 LGPL 疑点未闭环前不开视频流）
音频焦点仲裁  VOICE_CALL > TTS > MUSIC > AMBIENT 单一所有者；唤醒词路由 Claw/Muse 可配
扩展 HAL      三类配件协议（16B 输入报表 500Hz；执行器寄存器含角度/到位/堵转）
BSP           双板实现：korvo1（验证板）/ kaleido_v1（样机）；板级能力画像驱动 UI/权限裁剪
```

音频链路（第一优先级）：2×PDM → I2S0 → AFE/WakeNet 常驻 → 意图路由 →（Claw LLM 或 Muse）→ 播放队列 → I2S1 → TAS5805M。

## 5. 代拍决策——**已全部确认（2026-10-24 负责人无异议）**

| # | 决策 | 现状依据 |
|---|---|---|
| P-1 | 摇杆/按键配件**降级为可选配件**（协议保留，非主打）——主打配件改为顶部传感器/摄像头 + 底部云台 | 10-24 新指示明确了上下两位的用途 |
| P-2 | 功放对外口径：**峰值 2×10W、连续 3–5W×2**（含宣传与验收） | 物理极限（PVDD/喇叭/热）诚实评估 |
| P-3 | **无 3.5mm 耳机口**：USB-C 数字音频，ES8388 以 DNP 焊盘预留 | 全数字链路的自然推论 |
| P-4 | 电池目标 2000–3000mAh（受"高倍率脉冲+厚度"约束，非越大越好）——Q-5 裁决后**偏上限取向，可在 V-14 envelope 中再放大** | 音频第一优先级的代价 |
| P-5 | 摄像头 OV2640 定焦首发，**自动对焦留高配 SKU**；无 TF 卡（NAND） | GPIO 余量 + 成本 |
| P-6 | App 一期运行时用 **Lua**（esp-claw 原生），wasm 二期评估 | 无鉴权前提下 wasm 隔离收益降低 |
| P-7 | Muse 的视频流功能**暂不启用**（LGPL 门禁），avatar 先静态帧 | 许可证合规门禁 R-7 |
| P-8 | BOM 红线 ≤$55 维持，工作预算 $50；超支裁决顺序按 R2 优先级（音频>显示>外设） | constraints R2/R4 |

## 6. 开放问题——**已全部裁决（2026-10-24 负责人）**

| # | 问题 | **裁决** | 落实 |
|---|---|---|---|
| Q-1 | 桌搭核心场景 | **平台型，不做功能预设**：默认出厂仅 AI 日常对话 + Claw 写 App；功能由用户经 App/顶部扩展/底部底座自定义 | KShell 主屏 = App 网格；出厂内置仅"对话/设置/时钟"级最小集；产品叙事以"可定制"为核心 |
| Q-2 | 唤醒主入口 | **同意默认方案**：唤醒词 → Claw 默认，Muse 会话中自动接管 | 音频焦点路由默认值，策略表用户可配 |
| Q-3 | 底座是否首发 | **先留接口，不随首发**；但接口设计必须充分考虑供电问题 | 底部 POGO 供电设计为 G2 连接器选型硬条件：主机侧 5V 轨预留 ≥1A 给底座 + 底座可自带 USB-C 供电（两路二极管合并或优先级切换，G2 定案） |
| Q-4 | 云端 LLM/TTS | **BYOK**：用户自行填写 API key（对接 esp-claw cap_llm_config；首版支持 OpenAI 兼容协议 + 国内主流） | 设置 App 内置密钥管理；无 key 时仅离线能力可用（唤醒+本地命令） |
| Q-5 | 整机尺寸 | **允许更大，不做特别限制**——按体验最优取尺寸 | V-14 envelope 重定义：电池可取 3000mAh+（805080 级）、喇叭箱体可放大（降 Fc 利好低频）、屏仍 2"（成本与定位不变） |
