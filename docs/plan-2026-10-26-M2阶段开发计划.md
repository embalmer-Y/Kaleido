## §1 V-42 — OOBE 首电配置向导 + BYOK 密钥体系

**目标**：key 不再烧进镜像；开箱首电引导到可用，全程 10-20 分钟
（§9 预估口径）。

1. **NVS 密钥层**（落 kaleido_bsp 或新 kaleido_secret 小组件）：
   namespace `ksec`，条目 = WiFi SSID/pass、ASR key（百炼）、LLM key
   （MiniMax JWT）。读写 API + 擦除命令。回落链 **NVS → CONFIG（HIL
   开发后备）→ 空**。
2. **首电检测与三态判定**：NVS 无 key → 无 key 态（§9 三态矩阵 L0：
   本地模板应答"我还需要一把钥匙才能开口说话"+ 引导；离线命令词小集
   后续接）。该判定做成显式 `oobe_state()` 供各子系统查询。
3. **配置通道两档**：
   - **档一（本次落地）：串口控制台向导**——零新依赖，逐项输入 +
     即测即显（每步存证：WiFi 连通 ✓/✗ → ASR 探活 → LLM 一句真问 →
     TTS 一句真说，复用 tools/cloud_probes 探针逻辑的设备端版）。
   - **档二（产品形态，探针先行）**：esp_hosted SoftAP + captive
     portal 手机配网页。**前置探针 V-42a**：esp_hosted 2.12.9 的
     SoftAP 模式在本板的可用性（hosted AP 支持矩阵未验证；不行则
     串口向导为出厂形态、手机 App 二期）。
4. **key 失效降级链**（§9）：屏显徽标（M1.6 后补）+ 停点火 → TTS 降
   预置 → 仅本地能力，绝不沉默失能。

**门禁判据**：全片擦除 → 首电进向导 → 串口配 key（每步即测即显）→
免按键全链对话 → 断电重启 key 保持 → 擦除命令回到无 key 态；
`CONFIG_KS_MM_KEY` 出厂镜像为空。

## §2 V-43 — 会话状态机 + 音频所有权仲裁（M2 语音主体）

**目标**：消灭按键，把 HIL 变产品循环。评审 §7 建议 ① 的落地。

1. **显式状态枚举** `idle → listening → round → re-listen`（+ offline/
   unconfigured 三态叠加），所有音频任务对状态机负责：
   - **单一采音所有者**：idle 态 wakenet 持麦；round 态唤醒引擎让渡
     （真停止路径：停止标志 + 任务收尾 + AFE destroy，补上 V-40 留白）；
   - **一切放音经 s_pb 汇聚**：beep/cue/TTS 统一入播放流，扬声器唯一
     写者（audio_io 互斥锁之上再立所有权纪律）。
2. **免按键闭环**：唤醒词 → 双鸣 → 采音（VAD 或定时窗）→ ASR → LLM
   → TTS → 回监听。
3. **防自唤醒 V1**：TTS 播放期静音窗口（暂停 wake 检测）——AEC 落地
   前的过渡项（V-46 替换）。

**门禁判据**：连续 ≥10 轮唤醒→对话→回监听零人工干预、零 panic、
内存曲线平稳（每轮 heap 快照无单调劣化）。

## §3 V-44 — M1.5 验收线终裁（流式早切）

**目标**：给 1.5s 线一个有数据的裁决，结束悬案（台账：3.8→3.0s，
MiniMax 云端段 1.07s）。

1. **早切**：ASR partial 后按静音/语义端点提前起 LLM（不等
   finish-task 定稿）；子句泵与打断语义随之复核。
2. **干净网络延迟分布**：≥30 轮 P50/P90（嵌入式轮 + 真人轮各一组；
   复测前确认无后台占带宽——上次被听书流量污染）。
3. **裁决**：P50<1.5s 达成 → 验收过线；否则按方案 §3 建议修订对外
   承诺口径 1.5-2.5s 并记录取舍。裁决结论回填台账与 V-38。

## §4 V-45 — 舞台×语音联动（M1.6 表达基座 L0）

**目标**：角色第一次"活着"——语音事件驱动舞台状态。

1. **合并运行**：dsi-lvgl 舞台与 voice-loop 同应用（同核任务 + 事件
   即可，无需跨片）；PSRAM 预算过账（舞台 3 缓冲 ≈1.2MB + 播放 768KB
   + AFE 393KB 对照预算表 v2 余量 ~2.7MB，超则砍播放缓冲）。
2. **舞台状态机**：idle 呼吸 / 倾听侧耳 / 思考 / 说话——L0 用现成
   lottie 分段或参数化动效（23 词表 EAF 映射属 M1.6 后续，L0 只需
   四态可辨）。
3. **kaleido_express L0 骨架**落组件（W-6 形态已由 V-35R/V-39 实证：
   thorvg 走 pthread + LVGL 任务合成）。
4. OOBE 联动：无 key 态舞台 = 引导页（§9 矩阵第一列）。

**门禁判据**：唤醒/说话/思考三态切换肉眼可辨且动效无新瑕疵（V-39
口径不回退）；渲染预算不超 V-34 结论（325²@30fps 单核 <70%）。
