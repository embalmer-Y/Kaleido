## §3 缺陷清单

严重度：阻断（功能死/流程红，必须先修）＞严重（数据丢失/安全/逻辑错）＞一般 ＞ 建议。
行号以当前 HEAD（018bd763）为准。

### 阻断

**A1 valence 动力学死机：`s_prev_error_mean` 更新时机错误，raw_v 恒为 0**
`components/kaleido_emotion/src/kaleido_emotion.c:90,113-117,120`
```c
float e_mean = s_prev_error_mean;          /* :90 */
if (in->have_drive) {
        e_mean = in->drive_error_mean;
        ...
        s_prev_error_mean = e_mean;        /* :116 先更新 */
}
float raw_v = -(e_mean - s_prev_error_mean); /* :120 后差分 → 恒 0 */
```
`have_drive=true` 时先写 `s_prev` 再差分（差为 0）；`have_drive=false` 时 `e_mean`
初值即 `s_prev`（差也为 0）。**raw_v ≡ 0 恒成立**，valence 永远停在 0（唯一例外是
reappraisal 通道），`ethics_latched` 因此构造性不可达、anim_tag 永远落在中性带——
实证即 §2 中 `golden_constant_error` / `golden_ethics_latch` 两条 FAIL。
这确认了负责人怀疑的"一步偏差"，且实际比一步偏差更彻底。
修复：先 `raw_v = -(e_mean - s_prev_error_mean)`，后 `s_prev_error_mean = e_mean`
（注意 `!have_drive` 分支本拍不得更新 `s_prev`，现写法该分支恰好不动，位置对调后语义即正确）。

**A2 两套黄金轨迹提交时为红（从未运行）**
`components/kaleido_emotion/test/test_kaleido_emotion.c`、
`components/kaleido_ignition/test/test_kaleido_ignition.c`、`tools/hil/soul-test/`
emotion 侧两条 FAIL 暴露的是 A1（期望值本身是公式手算、方向正确——是**好测试抓到真
bug**）；ignition 侧两条 FAIL 是**测试自身算错权重**：`hysteresis_band`（test:81-84）
与 `proactivity_penalty`（test:103-110）单因子 0.9 / 0.75 经 0.2 等权后 S=0.18 / 0.15，
永远 < T_high=0.70/0.80，断言从第一天起就不可能为真——属"未跑过也没推导"的伪期望。
修复：改测试输入（如五因子 0.9）或断言值；并把两套套件接入 `tools/host-tests` 主机
回归（与 km/kp 同法 gcc 直编），soul-test 仅作板端复核。

### 严重

**S1 kaleido_memory：满配条目 JSONL 行截断 → seq 水位丢失 + 静默数据丢失（已实证）**
`components/kaleido_memory/src/kaleido_memory.c:59-85（ep_to_json）, 138-154（km_append）`
`line[KM_LINE_MAX=512]` 上 `strlcpy` 截断无任何检查：summary 189B（结构体自身容量内）
+ 8 facts + 6 tags 即超 512B（实测落盘 511B 非法 JSON）。后果链：reload 时该行解析失败
→ `km_init` 水位丢失（实测 seq=0）→ 后续 append 从 1 重复分配 seq；检索 0 命中。
修复：`ep_to_json` 返回序列化长度，`km_append` 校验 `strlen(s) >= outsz-2` 则拒写
返回错误（或扩 KM_LINE_MAX 至 1024 并压缩 facts 容量），`km_init` 对非法行计数告警。

**S2 kaleido_persona：id 无路径安全校验，注册表目录逃逸（已实证）**
`components/kaleido_persona/src/kaleido_persona.c:56（REQ_STR id）, 295-311（set_active）, 321-322（拼路径）`
25号 §2.3 只对 `asset`/`system_prompt` 执行了路径纪律，`id` 直接拼进
`<dir>/<id>/persona.json`：实测 `kp_set_active("../escape")` 逃逸成功。恶意/损坏包可
将激活指针指向注册表外任意可预测路径。修复：`kp_parse` 对 id 复用 `path_safe` 并加
字符白名单（`[A-Za-z0-9._-]`，禁 `/`），`kp_set_active` 二次校验且要求 id 已注册。

**S3 kaleido_ignition：NULL 防御失效——检查前解引用 cfg**
`components/kaleido_ignition/src/kaleido_ignition.c:49` `float t_high = cfg->t_high;`
先于 `:51 if (!ctx || !cfg || !f || !out) return;`。`cfg=NULL` 直接读野地址崩溃，
守卫成死代码。修复：声明移到判空之后（顺带消除混块声明）。

**S4 kaleido_ignition：主动度惩罚覆盖滞回状态机**
`components/kaleido_ignition/src/kaleido_ignition.c:62-71`
`holding && s < t_low` 的撤防结果在 `proactivity < 2` 分支被 `over_high = s >= t_high`
整体重算覆盖：带内（0.5~0.7）持火态被静默翻转，滞回语义仅在默认主动度下成立。
修复：惩罚只抬高 `t_high`，滞回判定（含 holding 撤防）只做一次。

**S5 gateway.py：双泵只等 FIRST_EXCEPTION，干净断开挂死（已模拟实证）**
`/home/emb/project/Kaleido/server/voice-gateway/gateway.py:100-104`
`asyncio.wait(..., FIRST_EXCEPTION)` 在**无异常**时等价 ALL_COMPLETED：设备或上游任一
侧正常关闭（`async for` 正常 return，恰是最常见路径）时另一泵不被唤醒、`upstream.close()`
不执行、`dev` 也不 close——会话资源悬置直到对端自身超时。修复：改
`return_when=asyncio.FIRST_COMPLETED`，任一泵结束即 cancel 另一泵并 close 双向 socket。

**S6 kaleido_emotion：ke_reset 不清函数内 static 积分器，二次初始化携带旧态**
`components/kaleido_emotion/src/kaleido_emotion.c:92-99（static val_int…/inited）, 202-214（ke_reset）`
积分器与 `inited` 是 `ke_step` 的函数级 static，`ke_reset` 清不到：同进程第二次起测
从上一局残值出发（A1 修完后该问题将显性化）；persona 的 `affect.initial`（kp_affect）
也因 `inited` 仅首次为假而永远无法注入。修复：积分器移为文件级 static 并在
`ke_reset` 一并清零/按 init 装载。

### 一般

**G1 controllability 违背 18号"无事件拍保持"**
`kaleido_emotion.c:163-166`：`else if (!in->action_receipt_success)` 恒真，bool 输入
无法表达"无事件"，无回执拍按失败向 0 衰减（且 τ 用 64，文档 τ_dec=16）——稳态恒趋 0。

**G2 two_step 与 18号构造式不符**

**G3 sp_dashscope 无断线/重连失效处理**
`sp_dashscope.c:191-226, 390-430`：vendored esp_websocket_client auto_reconnect 默认开

token 积压）。修复：DISCONNECTED 置 failed 并给出错误回调/快速失败。

**G4 ks_tts_first_pcm_us 返回语义与头文件不符**
`sp_dashscope.c:536-539` 返回 0；`kaleido_speech.h:80` 承诺"未到达为 -1"。且会话内
永不复位。修复：对齐 -1 哨兵。

**G5 llm_stream emit 满缓冲丢字节**

509B 无句读长句在边界处丢字节/破 UTF-8。修复：flush 后照常 append ch。

**G6 voice_loop tts_open 跨轮脏位**

**G7 memory match 加分无上界**

**G8 memory facts/tags 数组元素未验类型**

**G9 km_query 非法参数路径 fd 泄漏**

**G10 gateway 空 TOKEN = 无鉴权开放中继**
