## 过程缺陷（已修，立板级纪律）

**PSRAM 栈任务禁碰 NVS/flash**：W1 首版在 soul tick 内每拍调
`ksec_state()`（4 次 NVS 读）→ flash cache 关断窗口命中
`assert failed: spi_flash_disable_interrupts_caches_and_other_cpu
cache_utils.c:114 (esp_task_stack_is_sane_cache_disabled())` → SW_CPU_RESET
确定性与 RESET 自愈循环。修复：配置态在 soul_start()（app_main 内部
栈上下文）缓存一次（kaleido_secret 自身契约"写后即重启"使运行期
失配无害）。**该纪律适用于所有 kf_task_psram 任务**，纳入 coding
约定；后续 W4 littlefs 读写在 soul 任务内同样要走此审查。
